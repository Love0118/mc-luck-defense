# MomaDefense — 마크 운빨 디펜스

Paper **26.3 build 19 alpha**, Java **25** 기반의 개인 전장 디펜스 플러그인입니다. 클라이언트 모드는 필요하지 않습니다.

이번 버전은 진영·유닛·등급·소환·판매·배치·전투의 기반을 구현합니다. 웨이브와 최종 승리 조건은 아직 없습니다. 관리자가 적을 투입하는 개발용 전장으로 동작을 확인할 수 있습니다.

## 빌드 및 설치

Java 25와 Maven 3.9 이상에서 실행합니다.

```powershell
mvn -B -ntp clean verify
```

생성된 `target/moma-defense-0.1.0.jar`를 Paper 서버의 `plugins/`에 넣고 서버를 시작합니다. 서버와 API는 `26.3.build.19-alpha`로 고정했으며 실험 빌드입니다. 일반 Bukkit/Spigot/Folia 호환은 지원하지 않습니다.

- [Paper build 19 메타데이터](https://fill.papermc.io/v3/projects/paper/versions/26.3/builds/19)
- 서버 파일: `paper-26.3-19.jar`
- SHA-256: `f623c073913db7f21c6338eef22a00b19a8d87c1ef3115c2060d2382b90f4650`

## 바로 확인하기

관리자 권한으로 아래 명령을 순서대로 실행합니다.

```text
/moma create test
/moma join test
/moma spawn ZOMBIE 20
```

F키로 GUI를 열어 소환합니다. GUI를 닫고 포탑을 **좌클릭**하여 선택한 뒤, 빈 파란 배치 칸을 **좌클릭**하면 즉시 이동합니다. 선택 후 다시 F키를 누르면 상세 정보와 판매 버튼이 표시됩니다.

| 조작 | 동작 |
|---|---|
| F 또는 재지정한 보조 손 교환 키 | 소환·판매 GUI |
| 자신의 포탑 좌클릭 | 선택, 선택한 몹 변경 |
| 빈 파란 배치 칸 좌클릭 | 선택한 포탑 이동 후 선택 해제 |
| 경로·점유 칸·잘못된 위치 좌클릭 | 이동 거절, 기존 선택 유지 |
| 우클릭 | 포탑 조작 없음 |
| /moma leave | 전장 종료, 원래 위치·게임 모드 복구 |

조작 사거리는 24블록이며 블록에 가려진 대상은 선택하지 않습니다. 선택 효과는 소유자에게만 보입니다. GUI는 일반 좌클릭만 받으며, 중복 이벤트·더블클릭·Shift·숫자키·드래그로 재화가 중복 처리되지 않도록 제한합니다. 연속 구매는 5틱 간격으로 가능합니다.

## 명령과 전장

| 명령 | 권한 | 설명 |
|---|---|---|
| /moma list | moma.play | 전장 목록 |
| /moma join <이름> | moma.play | 비어 있는 개인 전장 참가 |
| /moma leave | 없음 | 현재 전장 종료 |
| /moma create <이름> | moma.admin | 전용 월드에 개발용 전장 생성 |
| /moma spawn <종> [수] [boss] | moma.admin | 자신이 참가한 전장에 적 1~100마리 투입 |
| /moma coins <금액> | moma.admin | 자신의 전장에 개발용 재화 1~1,000,000원 지급 |

`moma.play`는 기본 허용, `moma.admin`은 기본 OP 전용입니다. 전장 생성과 목록은 콘솔에서도 가능합니다. 적 종류는 `ZOMBIE/HUSK/DROWNED/SPIDER/SLIME/MAGMA_CUBE`입니다. `boss`는 보스 추가 피해를 확인하기 위한 표식이며, 보스 웨이브·전용 스탯은 아직 없습니다.

전장은 `moma_arenas` 월드에 128블록 간격으로 생성됩니다. 기존 블록이 있는 영역은 생성하지 않습니다. 파란 블록만 배치 칸이며, 붉은 정사각형 경로를 적이 시계 방향으로 반복 이동합니다. 바깥줄 북서쪽부터 시계 방향으로 채우고 이후 안쪽줄을 채웁니다. 판매된 칸을 다시 사용하며 다른 포탑을 당겨 채우지 않습니다.

한 전장에는 한 명만 참가합니다. 전장 목록·좌표는 `plugins/MomaDefense/arenas.yml`에 저장됩니다. **진행 중인 라운드·유닛·재화는 메모리에만 존재**하며 퇴장·접속 종료·서버 종료 시 정리합니다. 재접속 이어하기나 크래시 복구는 지원하지 않습니다. 정상 퇴장·종료에서는 이전 위치와 게임 모드를 돌려줍니다.

## 진영 및 전투

- 진영은 `ENEMY/DEFENDER`, UUID·전장·소유권은 서버 상태로 판정합니다. 엔티티에는 진영·전장·소유자 태그도 기록하지만 이름/태그를 게임 권한의 근거로 쓰지 않습니다.
- 아군과 적 외형은 겹치지 않습니다. `[적]`은 붉은 이름, `[아군] [등급] 종`은 등급 색상과 문자 표식을 사용합니다.
- 아군은 무적 포탑입니다. 적·플레이어에게 공격받지 않고 적을 추격하거나 길을 막지 않습니다.
- 바닐라 AI·자연 피해·햇빛 연소·분열·변신·드롭·자연 순간이동을 제어합니다. 실제 체력은 게임 상태에 있으며 바닐라 데미지와 분리됩니다.
- 사거리 내 누적 경로 진행 거리가 가장 긴 적을 우선합니다. 동률은 UUID 순서로 결정합니다. 한 바퀴를 돌아도 누적 거리는 유지됩니다.
- 준광역·대광역은 주 대상 중심의 원 안에 있는 같은 전장의 적을 공격합니다. 원이 공격 사거리 밖으로 일부 뻗어도 범위 피해가 적용됩니다. 근접 광역은 사거리 안 120도 부채꼴입니다.
- 다중 공격은 서로 다른 적만 때리며 부족한 대상 수를 중복 타격으로 채우지 않습니다.
- 적 처치 보상은 전장 소유자에게 한 번 지급합니다. 살아 있는 적이 제한 마릿수에 도달하면 즉시 패배하고 전투가 멈춥니다.
- 이동해도 공격 대기시간·연속 공격 상태가 유지됩니다. 대상이 바뀌면 연속 공격 강화가 초기화됩니다. 감속은 가장 강한 활성 효과만 적용합니다.

## 아군 24종

| 타입 | 몹 | 전설 이상 효과 |
|---|---|---|
| 근거리 단일 | 늑대·북극곰·판다·토끼 | 동일 대상 연속 공격 강화 |
| 근거리 광역 | 철골렘·호글린·염소·파괴수 | 감속 |
| 원거리 단일 | 스켈레톤·스트레이·보그드·피글린 | 보스 추가 피해 |
| 원거리 준광역 | 마녀·라마·눈골렘·가디언 | 중심 대상 추가 피해 |
| 원거리 대광역 | 블레이즈·가스트·위더 스켈레톤·워든 | 공격 반경 증가 |
| 원거리 다중 | 소환사·셜커·알레이·벡스 | 동시 공격 대상 수 증가 |

공격 방식은 외형의 바닐라 능력과 별개입니다. 24종을 균등하게 뽑으며, 등급과 독립 추첨하므로 총 216개 조합이 가능합니다. 모든 등급에서 타입이 유지됩니다. 타입 내 종마다 기본 공격력·공격 간격·사거리 등의 개발용 수치가 다릅니다.

## 등급과 경제

1회 소환은 **10원**입니다. 정수 가중치 합계는 정확히 100,000입니다.

| 등급 | 확률 | 판매가 |
|---|---:|---:|
| 일반 | 50.001% | 3 |
| 레어 | 33.1% | 6 |
| 고대 | 10.2% | 9 |
| 유물 | 5.1% | 16 |
| 서사 | 0.8% | 30 |
| 전설 | 0.5% | 불가 |
| 에픽 | 0.2% | 불가 |
| 신화 | 0.08% | 불가 |
| 태초 | 0.019% | 불가 |

전설 이상 획득은 서버 전체에 알립니다. 판매 가능한 결과의 소환당 평균 회수액은 5.46003원입니다. 천장·합성·교환은 없습니다. 재화 부족·빈 칸 없음·서버 엔티티 생성 실패 시 소환 비용을 차감하지 않습니다.

## 개발용 수치와 후속 작업

`config.yml` 기본값은 5×5 배치 칸, 시작 100원, 적 한도 100, 적 체력 80, 속도 초당 2블록, 처치 보상 2원입니다. 설정을 수정한 뒤 서버를 재시작합니다. 기존 전장의 크기는 생성 당시 값으로 유지됩니다.

아래 효과 수치와 `UnitType/Rarity`의 스탯은 전투 동작 확인용이며 최종 밸런스가 아닙니다. 특수효과 단계 L은 전설=1, 에픽=2, 신화=3, 태초=4입니다.

- 근접 단일: 연속 공격 5회까지, 피해 배율 `1 + 0.12 × L × (연속 횟수 - 1)`.
- 근접 광역: 40틱 감속, 감속률 `0.10 + 0.08 × L`.
- 원거리 단일: 보스 피해 배율 `1 + 0.5 × L`.
- 준광역: 중심 대상 피해 배율 `1 + 0.3 × L`.
- 대광역: 기본 반경에 `0.5 × L`블록 추가.
- 다중: 기본 대상 수에 `L` 추가.

웨이브, 보스 스탯, 승리 조건, 정식 맵, 재접속 복구, 전투 수치 외부 설정은 후속 설계 대상입니다. 이번 버전의 공격 표현은 피격 파티클이며 전용 발사체·스킬 애니메이션은 없습니다.

## 구조와 검증

- `dev.moma.core`: Paper와 독립된 유닛 정의, 확률, 배치, 소유권, 재화, 전투 상태.
- `dev.moma.paper`: 메인 스레드에서 실행되는 Paper 엔티티·이벤트·GUI·전장·명령 어댑터.
- `mvn clean verify`: 확률의 모든 경계, 216조합, 판매 제한, 실패 시 무차감, 보상 중복 방지, 전장 격리, 배치, 이동 중 상태 보존, 타입별 타격과 GUI 입력 보호 검증.
- 자동 검증은 실제 Paper API와 모의 어댑터를 사용합니다. 접속 클라이언트의 화면/조작·실제 서버 런타임 검증은 별도입니다. 체크리스트는 [docs/manual-verification.md](docs/manual-verification.md)에 있습니다.

MockBukkit 26.2는 26.3 레지스트리와 호환되지 않아 의존하지 않습니다. 빌드 산출물에는 테스트 라이브러리나 Paper API를 포함하지 않습니다.
