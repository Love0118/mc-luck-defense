# 광산과 공용 메뉴

광산은 48×48 블록, 입구 Y56·중간층 Y50·하층 Y44의 노이즈 동굴입니다. 가장 낮은 바닥은 Y40 베드락으로 입구보다 16블록 낮습니다. 3개 층마다 두 명씩 **광부 6명**을 배치하고 황금 안전모·가죽 작업복·철 곡괭이로 표시합니다. 가까운 7블록 내 플레이어를 바라봅니다. 목재 운반로·레일·랜턴과 주변 밝기 조명을 배치하고, 사다리 2개 수직 통로와 층 사이 계단 4개로 올라갈 수 있습니다. 자연 암반은 채굴 가능하며 구조물·외곽·천장·하한 베드락은 보호합니다.

노퀴와 광산에서 가젯·일반 아이템·착용 아이템·커서를 공유합니다. 광산 곡괭이와 고정 메뉴 도구는 광산에서만 지급합니다. 고정 슬롯을 채우기 전에 휴대 아이템을 빈 칸으로 옮기며 공간이 부족하면 입장을 취소하고 보존합니다. 광산 퇴장·접속 종료·재시작 시 공유 아이템을 먼저 저장한 뒤 원래 외부 인벤토리와 상태를 복원합니다. 복원 중 저장 오류가 나도 이미 저장한 공유 인벤토리에 외부 인벤토리를 덮어쓰지 않도록 영수증을 따로 기록합니다. 광산 상점에서 구매한 가젯도 같은 휴대 인벤토리에 지급하며 노퀴 아이콘 예약 슬롯에는 넣지 않습니다.

철 곡괭이는 기본 속도 50%, 최대 **300%**입니다. 성공하면 **1~10%p**가 무작위로 증가하며 최대치를 넘지 않습니다. 행운은 최대 III입니다. 속도는 Tool 컴포넌트로 적용하고 효율 인챈트를 사용하지 않습니다. 실패는 수치를 유지하며 파괴는 속도 50%·행운 0으로 초기화합니다. 기존 강화 수치와 일련번호는 유지합니다.

돌은 아이템을 지급하지 않습니다. 광물은 행운을 적용해 인벤토리에 즉시 표시하며 바닥에 드롭하지 않습니다. 휴대 아이템이 차지하는 칸까지 포함해 공간을 검사한 뒤 광석을 제거합니다. 미판매 물량과 별빛 거래는 DB가 관리하며 판매 화면은 이 기록만 사용하므로 외부 광물을 가져와 판매하거나 표시 아이템을 복사해 중복 판매할 수 없습니다. 노퀴에 돌아가도 같은 미판매 광물을 표시합니다. 공간이 부족해 표시하지 못한 물량도 판매 메뉴에는 전부 포함합니다.

노퀴 상점과 광부 상점 모두 **광석 판매**를 제공합니다. 광부 상점에는 곡괭이 강화도 표시합니다. 각 광물의 아이콘·단가·보유량과 일괄 판매 금액을 보여주며 같은 DB와 거래 영수증으로 정산합니다. 판매가 설정은 `mining.prices`이며 1~10✦로 제한합니다.

최초 광석의 25% 미만이 남으면 채굴한 빈 공간을 돌로 채우고 일부 돌을 서로 붙은 광맥으로 교체합니다. 원래 동굴 공간·통로·조명·상점·등반 구조와 플레이어 몸이 있는 곳은 보존합니다. 지형 변경은 기본 2,048블록/틱으로 나눠 처리합니다.

이번 배포는 광산 지형을 `shallow-lit-terraces-v3`로 한 번 재생성합니다. `mining/mining.db`의 미판매 광물·강화·미완료 거래·원래 인벤토리 및 Noqui 별빛을 보존하고 곡괭이를 초기화하지 않습니다. 레이아웃 표식을 저장해 이후 재시작 시 같은 지형을 다시 만들지 않습니다.

마운디 로비 나침반에는 마운디 게임 참가만 표시합니다. 노퀴·광산의 나침반에서는 마운디 참가·관전 또는 광산을 선택합니다. 출제권 기본가는 100✦입니다. 환경설정의 포탈챗 수신과 다른 소환 알림은 기본 OFF이며 기존의 명시적 설정은 유지합니다.
