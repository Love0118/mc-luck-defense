# 광산과 공용 메뉴

미니게임 나침반에서 **마운디**를 누르면 게임 참가와 활성 세션 관전 화면이 열립니다. **광산**을 누르면 전용 동굴에 입장합니다. 마운디 플레이 중에는 기존 세션 종료 규칙이 적용됩니다.

광산 입장 시 철 곡괭이를 지급합니다. 속도는 일반 철 곡괭이의 50%로 시작하며, 25%p씩 최대 200%까지 강화합니다. 속도는 아이템의 Tool 컴포넌트에 적용하며 효율 인챈트를 사용하지 않습니다. 행운은 최대 III입니다. 속도 강화 비용은 단계별 30·60·90·120·150·180✦, 행운은 60·120·180✦입니다.

동굴의 광물은 서로 붙어 있는 광맥으로 생성합니다. 최초 광석의 25% 미만이 남으면 채굴한 공간을 돌로 채우고 일부 돌에 새 광맥을 생성합니다. 출입구와 통로는 보존하고 플레이어가 있는 공간은 채우지 않습니다. 생성과 재생성은 기본 512블록/틱으로 나눠 처리합니다.

| 광물 | 개당 별빛 |
|---|---:|
| 석탄·구리·레드스톤 | 1✦ |
| 철·청금석 | 2✦ |
| 금 | 3✦ |
| 다이아몬드 | 4✦ |
| 에메랄드 | 5✦ |

돌은 판매하지 않습니다. 판매 가격 설정은 최대 5✦로 제한합니다. 직접 채굴한 광물은 전용 저장소에 누적하고 상점의 **광석 판매**로 정산합니다. 외부에서 가져온 아이템은 판매할 수 없습니다. 상점은 노퀴의 공용 상품과 곡괭이 강화를 제공합니다. 노퀴에서 사용하는 실물 가젯은 노퀴 로비에서 지급됩니다.

광산의 채굴 상태·광물·강화·처리 중인 거래·원래 인벤토리는 `plugins/MCLuckDefense/mining/mining.db`에 저장합니다. 별빛은 기존 Noqui 지갑을 공유합니다. 판매와 강화는 거래 ID로 재시도하여 중복 지급과 중복 차감을 막습니다. 퇴장·접속 종료·재시작 시 기존 인벤토리를 복구합니다. 광산 이용자가 있으면 런타임 교체를 막으며, 정상 서버 재시작은 복구를 먼저 수행합니다.

`plugins/MCLuckDefense/config.yml`의 `mining` 항목으로 생성량·가격·강화 비용을 설정합니다. 기본값은 플러그인에 포함됩니다. 전용 월드는 `moma_mining`이며 다른 미니게임 맵에 광맥을 생성하지 않습니다.

노퀴 로비·마운디 로비·마운디 게임에는 **치장** 아이템을 지급하며, 보유한 치장을 장착·해제할 수 있습니다. 출제권 기본 판매가는 **100✦**입니다. 환경설정의 **챗미러**는 `/chatmirror on/off`와 같은 외부 채팅 수신 설정을 사용하며 외부로 채팅을 보내는 권한이나 모드는 바꾸지 않습니다.
