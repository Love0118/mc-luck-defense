# 1.0.4 — 상위 특성·챌린지 도전

## 교본·정석·특성 슬롯

- 기존 여섯 교본의 해당 몹 피해를 +12%에서 **+25%**로 높인다.
- 상위 특성 **○○의 정석** 여섯 개를 추가하며 해당 몹 피해는 **+35%**다.
- 효과와 해금 조건에 피해 유형 대신 적용되는 네 몹의 이름을 표시한다.
- 교본은 150라운드, 정석은 500라운드 도달 시 해당 네 몹의 누적 유효 피해 비중 70% 이상으로 해금한다. 과잉 피해는 제외한다.
- 최고 1,500라운드 도달 시 네 번째 특성 슬롯을 영구 해금한다. 기존 100·250·500라운드 슬롯은 유지한다.
- 기존 교본 해금·장착 기록과 최고 라운드를 유지한다. 이미 1,500라운드에 도달한 계정도 네 번째 슬롯을 사용할 수 있다.

## 소수 정예

**로비 특성책 → 과녁 챌린지 도전 → 소수 정예 도전**을 누르면 현재 특성으로 새 게임을 시작한다. 게임 시작부터 끝까지 배치는 최대 10마리이며 대기석 48마리는 포함하지 않는다. 초과 소환은 대기석으로 가고 합성·승급·자리 교환을 유지한다. 자동 배치와 수동 이동 모두 한도를 지킨다.

| 도달 라운드 | 일반 적 피해 |
|---:|---:|
| 500 | +12% |
| 600 | +14% |
| 700 | +16% |
| 800 | +18% |

일반 게임에서 일시적으로 배치를 줄여 조건을 충족할 수는 없다. 소수 정예 도전으로 시작한 게임만 인정한다.

## 신속한 정리

500라운드부터 마지막 적 등장 후 **게임 시간 5초 이내에 전장의 적 전부를 처치**하면 성공이다. 이전 라운드의 잔여 적과 보스도 포함하며 5초 경계까지 인정한다. 배속·실제 경과 시간 대신 게임 틱을 사용한다. 실패하면 현재 연속 성공 횟수만 초기화하며 같은 게임에서 재도전할 수 있다.

| 연속 성공 라운드 | 공격속도 |
|---:|---:|
| 30 | +10% |
| 60 | +12% |
| 90 | +14% |
| 120 | +16% |
| 150 | +18% |

## 제한 예산

게임 시작부터 목표 라운드 진입까지의 성공 구매 비용을 합산한다. 판매 환급을 차감하지 않으며 자동판매 구매도 포함한다. 각 단계는 독립 판정한다. 예산을 넘겨도 게임은 계속되고 다음 단계 조건에 도전할 수 있다.

| 도달 라운드 | 총 소환 비용 상한 | 적 처치 골드 |
|---:|---:|---:|
| 500 | 1,500,000골드 | +10% |
| 600 | 2,000,000골드 | +12% |
| 700 | 2,500,000골드 | +15% |
| 800 | 3,000,000골드 | +18% |

제한 예산과 신속한 정리는 일반 게임과 소수 정예 모두 자동 판정한다. 새 챌린지에 미라클 획득 조건은 없다. 관리자 개입 판은 기존 규칙대로 해금에서 제외한다. 게임 중 F 메뉴에 배치 한도·총 소환 비용·현재 연속 성공 횟수를 표시한다.

상위 보상은 기존 같은 계열을 교체하며 중첩 장착하지 않는다. 획득한 특성은 다음 게임부터 장착할 수 있다. 전체 목록은 [특성 안내](traits.md)와 [구현에서 생성한 목록](achievements-draft.md)에 있다.

## 저장·적용

버전은 **1.0.4**, 런타임 상태 형식은 **5**다. 특성 밸런스와 게임 상태가 달라지므로 **진행 중인 게임이 모두 끝난 뒤 `/mud update`를 실행**한다. 세션이 있으면 기존 업데이터가 적용을 거절한다. 세션이 없으면 서버 재시작 없이 적용할 수 있으며 `/mud version`으로 버전을 확인한다.

소수 정예 여부·총 소환 비용·현재 연속 성공 횟수는 호환되는 세션 유지 리로드에서 보존된다. 해금한 업적과 특성 선택은 계정에 저장한다. 새 챌린지는 과거 최고 라운드만으로 소급하지 않는다. 서버 종료나 접속 종료 뒤의 게임 이어하기는 지원하지 않는다.

특성책의 기존 교본 설명은 업데이트 직후 반영된다. 이미 Paper에 등록된 기존 도전과제의 기본 업적 화면 설명은 다음 정상 서버 재시작 후 바뀐다. 새 도전과제 등록과 해금 판정에는 영향이 없다. 라이브 게임을 종료하거나 서버를 재시작하지 않고 릴리스만 게시한다.

## 검증

`mvn -B -ntp verify`에서 **352개 테스트가 모두 통과**했다. 기존 테스트를 확장했고 새 파일 없이 두 항목만 추가했다.

- 10마리 제한의 소환·대기석·수동 이동·교환·자동 배치와 상태 저장
- 5초 경계, 500라운드 이전 제외, 실패 초기화, 150라운드 연속 성공과 리로드 중간 복원
- 예산 정확한 경계, 환급 제외, 단계 독립 판정, 일반 게임의 소수 정예 보상 차단
- 교본·정석의 몹별 피해와 네 번째 슬롯의 해금·저장
- 과녁 메뉴의 소유권·오래된 화면·중복 시작 방지

신규 예산과 5초 조건은 초기 운영 수치다. 이 검증은 판정 정확성을 확인하며 실제 플레이어의 달성률을 측정한 결과는 아니다.
