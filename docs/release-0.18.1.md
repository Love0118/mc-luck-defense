# 0.18.1 — 중복 기물 추첨 풀 보정

전우의 재회 단계를 10/15/20/25%로 변경했다. 같은 지급 등급의 최고 강화 기물 한 종을 대상으로 삼으며, 강화 수치가 같으면 먼저 획득한 기물이 대상이다. 다른 종류로 확률을 나누지 않는다.

종류 수 `n=24`, 보정 비중 `p`일 때 대상 종류는 `p + (100-p)/n`%, 나머지는 각 `(100-p)/n`%다. 25% 단계는 대상 28.125%, 나머지 23종은 각 3.125%로 합계 100%다. 등급을 먼저 추첨하고 종류에만 적용하므로 태초 등급 등장 확률은 그대로다. 전설 이상 한정, 해당 등급을 보유하지 않았다면 기본 균등 추첨을 유지한다.

첫 구매 승급 패시브의 의미는 변경하지 않았다. 가장 높은 단계를 해금하면 **처음 두 번의 성공 구매에서 일반~에픽 전체가 각각 한 등급씩 상승**한다. 일반→레어, 서사→전설, 전설→에픽, 에픽→신화이며 신화·태초는 그대로다. 낮은 단계의 패시브를 중첩해 +2, +3으로 올리지 않는다.

Maven 284개 테스트 통과. 모든 단계에서 24종 × 100개 보정 난수 구간을 전수 검사하여 각 종류의 정확한 비중을 확인했고, 동률의 단일 대상·최고 강화 변경·승급 대상 전체 등급도 검증했다. [시뮬레이션](simulation/traits-0.18.1/REPORT.md)은 별도로 보관한다.

밸런스 변경이므로 게임 세션이 없는 상태에서 `/mud update`로 적용한다. 라이브 서버에는 직접 적용하지 않았다.
