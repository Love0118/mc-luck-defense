# 1.0.42 — 안전 업데이트의 줄바꿈 오판 수정

1.0.40 Windows 설치본에서 Linux로 빌드한 1.0.41로 업데이트할 때, 내용이 같은 `config.yml`, `rewards.yml`, `wave-themes.tsv`의 줄바꿈만 CRLF에서 LF로 바뀌어 로더 호환성 검사가 실패했습니다.

`config.yml`과 `wave-themes.tsv`는 CRLF로 고정하고, `rewards.yml`은 기존 설치본의 혼합 줄바꿈을 원본 그대로 보존합니다. 빌드 리소스의 줄바꿈을 검증하는 회귀 검사도 추가했습니다. 실제 설정값, 로더, 의존성, 세션 형식, 밸런스는 변경하지 않습니다. 로더의 해시 검사는 유지합니다.

1.0.42의 Linux 배포본은 로더 검사는 통과하지만 `campaign.properties`의 줄바꿈 때문에 진행 중인 세션에서 밸런스 검사에 걸릴 수 있습니다. 이 부분까지 수정한 [1.0.43](release-1.0.43.md)을 사용하세요.

검증: Java 테스트 582개, Python 테스트 24개, 4판 시뮬레이션 검사를 통과했습니다. LF 기본 체크아웃에서도 기본 리소스 바이트가 유지되는지 확인했습니다. 로컬 빌드는 1.0.40의 로더·밸런스·세션 형식 검사를 통과했으나 Linux 배포본의 최종 검사에서 밸런스 리소스의 줄바꿈 차이를 추가로 발견했습니다.
