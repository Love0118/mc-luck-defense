# 0.20.0 — 특성 장착 기준 전체 진행 곡선

현재 보정 후보를 검증 중이다. 10만 판 검증 전에는 자동 업데이트 배포 대상으로 올리지 않는다.

## 기준

특성 장착 플레이를 후반 난이도의 주 기준으로 삼는다. 무특성의 30·60·100·200라운드는 기존 목표를 참고하되, 무특성 2,000라운드 10만 판 중 1~2회는 더 이상 필수 보정 조건으로 쓰지 않는다.

- 무특성: 특성·패시브 없음.
- 중간 티어 장착: 강화 효율 +15%p, 중복 기물 보정 +15%p, 처치 골드 +4%. 첫 두 구매 에픽 이하 +1 및 초반 서사·전설·에픽 보정 패시브.
- 최고 성장: 강화 효율 +30%p, 중복 기물 보정 +25%p, 처치 골드 +8%. 모든 패시브.
- 최고 합성·전투: 피해 +21%, 중복 기물 보정 +25%p, 강화 효율 +30%p. 모든 패시브.
- 별도 보정 비교: 피해 +21%, 공격속도 +8%, 강화 효율 +30%p. 중복 특성이 없는 구성과 장기 합성 차이를 확인한다.

중간 티어는 비교용 구성이다. 실제 이용자의 장착 분포를 조사한 결과가 아니다. 최고 두 구성도 가능한 모든 조합 중 최적이라는 의미가 아니다.

## 전투 수치와 실행기

진 태초 기본 피해는 같은 종 태초의 100배, 미라클은 진 태초의 100배로 조정한다. 기존에는 각각 34배였다. 사거리·공격 간격·역할, 소환 확률과 판매가는 유지한다. 기존 +20 피해 계승 규칙을 유지하므로 많은 하위 재료를 계승한 개별 기물의 실제 배율은 기본 피해 배율과 다를 수 있다.

1~10,000라운드 체력 기준점을 명시한다. 필드·출현 패턴은 100라운드마다 반복하고, 체력은 반복하지 않는다. 관측 범위 이후에는 기존 제곱 연장 규칙을 사용한다.

시뮬레이터는 사용 가능한 논리 프로세서 수만큼 독립 게임을 병렬 처리한다. 500틱은 묶음 크기이며 실제 속도 제한이 아니다. 게임 틱을 생략하지 않아 배속별 공격·구매·합성 규칙을 유지한다. [성능 검증](simulation/simulator-performance-0.20.0/README.md).

같은 시드에 네 구성을 적용한다. 소규모 보정에는 32,000,000번대, 최종 검증에는 별도의 34,000,000번대 시드를 사용한다. 최종 결과는 원본 전체의 누락·중복·경제·도달 판정을 재검사해 작성한다.

## 적용

밸런스가 바뀌므로 기존 활성 게임을 유지한 상태의 업데이트는 호환성 검사로 거절된다. 게임이 끝난 뒤 안전 리로드로 적용할 수 있다. 서버 재시작 없이 업데이트 파일을 준비한다.
