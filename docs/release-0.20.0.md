# 0.20.0 — 연속 난이도 곡선·상위 소환 조기 해금

100라운드 주기가 바뀔 때 일반 적의 총 체력이 떨어지던 문제를 수정했다. 최고 티어 특성을 기준으로 2,000라운드 도달 목표는 **1만 판 중 1~2판(0.01~0.02%)**, 실질적인 끝 구간은 2,500라운드 부근이다. 2,500에서 강제로 종료하지 않으며 이후에도 난이도는 계속 상승한다.

사용자가 희귀 분기 시험 결과를 검토한 뒤 현재 수치를 확정했다. 목표 도달률은 아직 10만 판 검증이 끝난 측정값이 아니다. [진단 결과와 검증 상태](simulation/pressure-model-0.20.0/REPORT.md).

## 난이도

1~100라운드는 기존 초반 기준점을 사용한다. 이후 기준 체력은 다음 식으로 증가한다.

`H(r) = 48,000 × (r / 100)^3.1 × ((1 + (r / 1,000)^2) / 1.01)^1.3`

일반 적의 라운드 총 체력을 `32 × H(r)`로 맞춘다. 적 종류·마릿수·이동 속도·출현 순서는 반복하지만 총 체력은 주기 경계에서도 내려가지 않는다. 일반 적 총 보상은 기존 후반 보상 단가의 31배이며, 0.1골드 단위로 정확히 분배한다. 보스는 10라운드마다 유지하며 체력은 같은 연속 곡선을 따른다. 워든으로 여러 적을 묶어도 총 체력과 골드를 보존한다.

진 태초의 기본 피해는 같은 종 태초의 100배, 미라클은 진 태초의 100배다. 사거리·공격 간격·역할과 +20 피해 계승 규칙은 유지한다. 특정 등급 보유 여부로 승패를 강제하지 않는다.

## 소환

| 라운드 | 소환 비용 | 등장 최저 등급 |
|---:|---:|---|
| 1~100 | 10 | 일반 |
| 101~499 | 100 | 유물 |
| 500~999 | 2,000 | 전설 |
| 1,000 이후 | 5,000 | 에픽 |

상위 두 단계의 확률·판매가를 함께 조정했다. 전체 수동판매 회수율은 각각 49.8893%, 49.88184%다. 이미 구매한 기물은 원래 판매가를 유지하며 합성 시 재료 판매가를 합산한다. GUI 확률표·책 종류·비용은 해금과 동시에 바뀐다. 신화 전체 방송은 500라운드부터, 태초 방송은 1,000라운드부터 제외한다. [정확한 확률·판매가](summon-economy.md).

## 검증과 적용

Java 테스트 344개와 결과 검증기 Python 테스트 3개를 통과했다. 1~10,000라운드 일반 적 총 체력 증가, 보스 증가, 정확한 골드 합계, 소환 구간 경계, 판매·합성, GUI 확률표, 1배·32배 구매 동작을 확인했다.

선별한 희귀 시드를 실제 게임 규칙으로 재생했을 때 두 미라클 보유 세션이 각각 2,484·2,543라운드에서 적 수 제한으로 종료했다. 이 선별 시험으로 전체 도달률을 계산하지 않는다. 별도의 무작위 10만 판은 로컬에서 동일한 확정 수치를 측정한다. GitHub 대규모 시뮬레이션은 실행하지 않는다.

상태 형식은 3으로 바뀐다. 진행 중인 게임이 있으면 이번 업데이트를 거절하고, 게임 종료 후 안전 리로드로 적용한다. 서버를 재시작하거나 기존 세션을 강제로 종료하지 않는다.
