# 0.18.3 — 처치 골드 특성·강화 합성 선택

전장의 투자를 적 처치 골드 **+2 / 3 / 4 / 6 / 8%**로 변경했다. 기존 누적 소모량에 따른 피해 증가는 제거했다. 일반 적과 보스 보상에 적용하며 시작 골드·판매 환급·관리자 지급은 늘리지 않는다. 0.1골드 미만의 보너스는 다음 처치로 이월한다. 기존 골드 소모 업적과 특성 장착 ID는 유지한다.

F 메뉴의 자동 배치와 배속 사이에 **강화 합성 ON/OFF** 모루 버튼을 추가했다. 기본은 ON이다. OFF에서는 같은 종·등급도 별도 기물로 배치한다. ON으로 전환해도 기존 기물을 즉시 합치지 않고 다음 구매부터 합성한다. 전환 시 클릭 소리를 내며 ON/OFF 상태를 색상과 문자로 표시한다.

설정과 소수 보상 잔여분은 세션 저장·복원에 포함한다. 오래된 세션은 합성 ON으로 읽으며, 구형 투자 특성은 같은 업적 ID의 골드 특성으로 변환한다. 실제 게시된 0.18.2 JAR로 작성한 스냅샷의 골드·기물·강화·누적 소모 보존도 별도 검사했다.

수치 선택과 비교 결과는 [시뮬레이션 보고서](simulation/gold-income-0.18.3/REPORT.md)에 기록한다. 기본 적 체력·뽑기 확률·판매가는 변경하지 않았다. 이번 수치는 강화 합성 ON을 기준으로 비교했다.

로컬 Maven verify의 295개 테스트를 통과했다. 소수 보상 누적·중복 지급 방지·판매 제외·구형 특성 복원, 합성 설정·소유권·빈 칸 제한·GUI 중복 클릭, 공속 특성과 골드 보너스를 함께 적용한 1배/16배 게임 상태 일치를 검사했다. 무특성 64시드의 결과는 게시된 0.18.2와 모든 기록이 동일했다.

밸런스 변경이므로 진행 중인 게임을 마친 뒤 `/mud update`로 적용한다. 서버를 자동 재시작하지 않는다.
