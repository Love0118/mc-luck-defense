# 개인별 최고 라운드 리더보드

기존 스폰 앞 순위표 옆에 ▲ 이전 페이지 / ▼ 다음 페이지를 표시합니다. 버튼을 좌클릭하거나 우클릭하면 10명 단위로 순위를 넘깁니다. 상단은 현재 페이지/전체 페이지, 순번은 전체 순위입니다. 첫 페이지 이전이나 마지막 페이지 다음으로 이동하지 않습니다. 같은 클릭의 중복 이벤트와 보조 손 동작은 중복 처리하지 않습니다.

페이지 상태는 접속자 UUID별로 독립적입니다. 개인 TextDisplay를 spawn 전에 setVisibleByDefault(false)로 만들고 소유자에게만 showEntity를 호출합니다. 따라서 다른 사람의 페이지 텍스트는 해당 클라이언트에 전송되지 않습니다. Paper의 엔티티 추적·메타데이터 패킷을 사용하므로 Via도 일반 엔티티처럼 변환합니다. 이전/다음 버튼 두 개와 버튼 글자는 공유합니다.

로비에 있는 플레이어당 개인 순위표 1개, 전체 공용 표시/클릭 엔티티 4개입니다. 다른 월드로 이동하거나 접속을 종료하면 개인 표시는 제거하고, 로비 재입장은 1페이지부터 시작합니다. 관련 청크를 유지하고 삭제된 표시를 1초마다 복구합니다. 기록은 변경 시 현재 각자의 페이지에 반영됩니다. 플러그인 종료/런타임 교체 시 리스너·작업·엔티티·청크 티켓을 정리합니다.

2026-09-21 검증:

- 독립 체크아웃의 전체 테스트 252개 통과.
- ViaVersion/ViaBackwards 5.12.0과 1.21.8 프로토콜 클라이언트 2명으로 테스트.
- 실제 우클릭 패킷으로 첫 번째 플레이어만 11~20위로 전환, 두 번째 플레이어는 1~10위 유지.
- 각 클라이언트에 상대의 개인 표 엔티티 생성/메타데이터 패킷이 전달되지 않음 확인.
- 개인 표 강제 제거 후 동일 페이지·개인 가시성으로 복구 확인.
