# 1.0.6 — BGM 팩 반복 다운로드 차단

2026년 9월 27일 오라클 서버의 BGM 78곡은 모두 Dropbox 공유 주소와 팩 해시를 가지고 있었다. 그러나 샘플의 Dropbox 주소는 ZIP 대신 `Link Temporarily Disabled` HTML을 반환했다. 접속 클라이언트는 16개 팩 중 15개 다운로드 실패를 표시했고 서버 로그에도 복구 실패가 반복됐다.

준비가 끝난 팩을 시작 시와 30분마다 서버가 전부 다시 다운로드해 SHA-1을 검사하던 동작을 중단했다. 업로드 완료 시 팩 검증은 유지한다. 팩 형식이 오래되었거나 배포가 완료되지 않은 곡의 생성·복구는 유지한다. 기존 곡, Dropbox 링크, 해시, 재생 목록을 바꾸지 않는다.

Dropbox 도움말에 따르면 이 오류 페이지는 24시간 동안 링크가 지나치게 많이 공유되거나 다운로드된 경우 나타나며, 복구를 위해 24시간을 기다리라고 안내한다. 첫 발생 후 계정 공유가 멈춘 경우에도 24시간이 걸릴 수 있으며 반복되면 더 오래 지속될 수 있다. 제한 해제 시각은 Dropbox 계정 상태에 따라 다르며 플러그인만으로 즉시 풀 수 없다. [Dropbox 공유 제한 안내](https://help.dropbox.com/share/banned-links)

서버의 반복 검사 트래픽을 제거해 제한 재발 위험을 줄인다. 클라이언트가 여러 곡을 미리 받는 트래픽은 남아 있다. 제한이 풀린 뒤 이미 실패 상태인 클라이언트는 BGM OFF→ON 또는 재접속으로 팩을 다시 요청해야 한다.

1.0.5와 런타임 상태 형식 5 및 밸런스 지문은 같다. 진행 중인 게임은 유지할 수 있지만, 현재 BGM 복구 작업이 돌아가는 동안 업데이터가 적용을 거절할 수 있다. 서버 프로세스는 재시작하지 않았다.

`mvn -B -ntp verify`에서 353개 테스트가 통과했다. 기존 BGM 복구 테스트에 준비 완료 팩의 재다운로드가 없는지 검증을 추가했으며 새 테스트 항목이나 파일은 만들지 않았다.
