# 소환 확률·판매가 · 0.19.0

라운드 진입 시 101R은 100골드, 1,000R은 1,000골드, 2,500R은 10,000골드 소환으로 전환한다. 단계 전환은 되돌아가지 않는다. 시작 보정 종료 후의 확률이다.

모든 표는 합계 100,000의 정수 가중치다. 0.001%는 10만 분의 1이며 천장이나 보장 횟수가 아니다. 신화·태초의 골드당 자연 획득량은 네 단계에서 같고, 진 태초는 1,000·10,000골드 사이에서 같다. 에픽은 마지막 단계의 확률 합계 제약으로 기존 골드당 획득량을 유지하지 않는다. 다른 하위 등급과 승급까지 포함한 전체 전투 가치를 완전히 동일하게 만든 표는 아니다.

새 소환 두 단계는 하위 결과의 판매가를 조정하여 회수율을 맞췄다. 기존 10·100골드의 일반~신화 가격은 유지한다. 태초 판매를 새로 허용하여 두 기존 단계의 전체판매 회수율도 약 1.9%p 오른다.

구매 시 해당 단계의 실제 판매가를 기물에 저장한다. 합성·승급은 재료값을 합산하므로 나중에 비싼 소환이 열려도 보유 기물의 판매가가 일괄 상승하지 않는다. 초반 특성으로 등급이 상승한 기물은 원래 추첨 등급의 판매가를 사용한다. 구형 저장에서 판매가가 0이던 태초·진 태초는 새 기본 판매가로 읽는다.
