# 1.0.24 — 100라운드 이후 세션 나가기 잠금

6번 칸 환경설정에 **100라운드 이후 세션 나가기 비활성화** ON/OFF를 추가했다. 기본값은 OFF이며 개인별 설정으로 저장된다. ON이면 자신의 진행 중인 게임이 100라운드에 진입한 순간부터 침대 우클릭과 `/mud leave`, `/mud lobby`로 나갈 수 없다. 나가기 요청 시 오류 소리와 환경설정에서 해제하라는 안내를 표시한다. 게임·로비·관전에서 설정을 바꿀 수 있고, OFF로 바꾸면 즉시 나갈 수 있다.

관전 종료와 로비의 포탈섭 이동에는 잠금을 적용하지 않는다. 패배·접속 종료·서버 정리·오류로 종료되는 세션은 기존대로 정리된다. 차단된 나가기 요청은 기물·적·골드·라운드·선택·BGM을 정리하지 않고 게임을 그대로 진행한다.

설정은 기존 플레이어 데이터에 별도 키로 저장하여 재접속 후 유지한다. 기존 소환·라운드 알림 키, 인벤토리 백업, 게임 저장 형식과 밸런스는 변경하지 않는다. 영구 로더도 변경하지 않아 기존 세션을 보존하는 안전 업데이트와 호환된다.

## 검증

99라운드 허용과 100·101·500라운드 차단, 설정 OFF 후 즉시 허용, 침대·명령어의 동일한 검사, 관전자의 나가기, 종료된 게임·접속 종료·서버 정리를 검사한다. GUI에서 중복·다른 사용자·닫힌 메뉴·하단 인벤토리·Shift 클릭으로 설정이 바뀌지 않는지 확인한다. 기존 알림 설정과 새 설정이 독립적으로 저장되는 것도 검사한다.

Java 검사 465개, Python 결과 검증기 3개, 유지보수 검사 19개를 통과했다. 기존 배포본과 핵심 게임 코드·영구 로더·런타임 저장 클래스가 동일하고 캠페인 설정도 같음을 확인했다. 실제 클라이언트의 GUI 표시나 라이브 세션 리로드는 이번 검증에 포함하지 않았다.

beta에 배포하고 로컬·Oracle update 폴더에 준비한다. 라이브 재시작·리로드는 실행하지 않는다.
