# 0.17.2 — 분할곡에서 전체곡으로 전환

사용자가 선택한 방식은 전체 OGG와 2초 분할 OGG를 함께 저장하는 기존 3세대 팩을 사용한다.

- 처음부터 듣는 사람: 전체곡 재생.
- 중도 관전자: 현재 재생 위치에 해당하는 분할곡으로 합류.
- 다음 곡 또는 같은 곡의 다음 반복: 전체곡을 한 번 재생하고 분할 재생 종료.
- 전체곡을 내려받았다는 이유만으로 곡 중간에 처음부터 틀지 않는다. 전체곡 전환 시점은 곡 시작 경계다.

0.17.1에서는 경계에서 서버 틱이 150ms 이상 늦으면, 분할곡을 듣던 관전자가 다음 곡에서도 분할 재생에 남을 수 있었다. 마지막으로 관찰한 곡·반복을 추적해 곡 전환을 인식하도록 보완했다. 음소거·세션 종료·팩 재로딩 시에는 이 상태를 초기화하므로 중간 재합류는 계속 현재 위치의 분할곡을 사용한다.

기존 3세대 팩은 재다운로드하지 않는다. 이전 2세대 팩의 자동 재생성 및 새 해시 다운로드는 0.17.1과 동일하다. 곡·재생 목록·전투 데이터·영구 로더는 바꾸지 않는다.

회귀 검사는 20초 곡에 중도 합류한 관전자가 여러 2초 경계와 틱 지연을 통과한 뒤, **다음 반복을 800ms 늦게 관찰해도 전체곡으로 전환**하는지 확인한다. 전환 후에는 해당 곡 도중 재생·중단 패킷을 반복하지 않아야 한다.

별도로 수행한 [단일 파일 우회 조사](bgm-single-file-research.md)와 오디오 계층 실험도 보관했다. 그 실험적인 선재생 방식은 제품에 적용하지 않았다.

검증: Maven 테스트 272개 통과. [beta CI](https://github.com/Love0118/mc-luck-defense/actions/runs/35687816666)에서 빌드·테스트·시뮬레이션·게시 성공. 게시된 JAR를 실제 업데이터로 다운로드하고 0.17.0과 영구 로더·밸런스·상태 스키마 지문이 같은지 확인했다.
