# 0.18.0 — 소모·합성 특성, 시작 패시브, 16배속

- 누적 소환 골드 소모 도전과제 5개와 같은 등급 전설 이상 중복 합성 도전과제 4개를 추가했다. 총 90개 업적, 장착 특성 64개와 패시브 보상 7개다.
- 전장의 투자: 누적 소모 업적으로 해금하며, 이번 게임 소환에 사용한 1,000골드마다 피해 +1%. 단계별 상한은 3/5/7/9/12%다.
- 전우의 재회: 전설 이상 소환에서 5/8/12/15% 확률로 같은 지급 등급의 보유 기물 중 최고 강화 종류를 추첨한다. 동률은 균등 추첨한다. 등급 확률·승급 조건은 유지한다.
- 서사·전설·에픽·신화 초반 보정은 해금된 등급마다 독립적인 패시브가 됐다. 첫 3회 성공 구매에서 각 4%, 해당 원래 등급을 뽑으면 해당 보정만 종료한다.
- 첫 구매 등급 +1도 패시브가 됐다. 해금한 가장 높은 단계 하나만 적용하며 에픽→신화가 상한이다. 기존 선택 목록의 패시브는 장착 슬롯에서 제외한다.
- F 관리 GUI와 `/mud speed`에 16배속을 추가했다. 게임 시작 시 선택 특성과 패시브를 고정하며 도중 해금은 다음 게임부터 적용한다.

새 누적 골드·상위 중복 통계는 업데이트 이후 성공 구매부터 집계한다. 판매 환급은 소모 기록을 되돌리지 않고, 실패 구매·관리자 개입 이후 구매는 계정 업적에서 제외한다.

[업적·특성 전체 목록](achievements-draft.md), [사용법](traits.md), [비교 시뮬레이션](simulation/traits-0.18.0/REPORT.md), [20 TPS 공격속도 검증](performance/0.18.0/REPORT.md).

Maven 테스트 282개 통과. 이후 16배속 변경을 포함한 관련 20개 검사도 통과했다. 별도 로컬 Paper 서버에서 360개 공속·배속 조합이 실측 20.000 TPS에서 이론 공격 횟수와 1회 이내로 일치했다. 실제 라이브 서버 재시작·업데이트는 수행하지 않았다.

이번 버전은 특성 밸런스가 바뀌므로 진행 중인 게임이 있으면 안전 업데이터가 거절한다. 게임 세션을 종료한 후 `/mud update`로 적용한다. 전체 서버 재시작은 필요하지 않지만 BGM 작업 중에도 안전 리로드를 보류한다.
