# 1.0.13 — 접속자가 없을 때 재시작

`/reboot est`는 관리자 또는 콘솔에서 빈 서버 재시작을 예약한다. 1초마다 온라인 플레이어를 확인하고, 모두 나가면 서버를 정상 종료한다. 같은 예약을 중복 등록하지 않는다. 서버에 사람이 없는 상태에서 콘솔로 예약해도 다음 확인 시 종료한다.

`/reboot cancel`은 대기를 취소한다. 인수 없는 `/reboot`는 기존처럼 다음 틱에 즉시 종료하며, 대기 중인 예약이 있다면 함께 취소한다. 게임 런타임 리로드·롤백·플러그인 종료 시 예약 확인 작업도 취소하므로 리로드 이후에는 다시 `/reboot est`를 실행해야 한다.

정상 종료 후 자동 시작은 서버 실행 관리자가 담당한다. Oracle Paper의 `mc-luck-defense.service`에는 이미 `Restart=always`, `RestartSec=5s` 설정이 적용되어 있다. 이 명령은 서버에 실제로 접속자가 없을 때만 사용하려는 관리 기능이며, 게임 세션이 끝났는지 따로 판정하지 않는다.
