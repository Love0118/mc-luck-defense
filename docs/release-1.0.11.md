# 1.0.11 — 재시작 명령을 세션 유지 업데이트로 제공

1.0.10은 `/reboot`를 영구 로더와 `plugin.yml`에 추가하여 기존 로더와의 호환성을 깨뜨렸다. 명령을 교체 가능한 게임 런타임으로 옮겨 이 문제를 수정했다. 1.0.9의 영구 로더와 `plugin.yml`을 복원하고 세션 상태 형식 5 및 밸런스 규칙을 유지한다. 따라서 **1.0.9 → 1.0.11은 `/mud update` 또는 `/mud reload`로 세션을 유지하며 적용**할 수 있다.

런타임 활성화 시 `/reboot`를 서버 명령 목록에 등록하고, 리로드·롤백·종료 시 해당 명령을 해제한다. 온라인 플레이어의 명령 목록도 갱신한다. 기존 명령을 덮어쓰지 않으며, 사용 권한과 중복 요청 방지는 1.0.10과 같다. 이번 수정에는 최초 설치를 위한 Paper 재시작이 필요하지 않다.

`/reboot`는 서버를 정상 종료한다. systemd 서비스에서 자동으로 다시 시작하려면 [설정 파일](../scripts/maintenance/mc-luck-defense-reboot.conf)의 `Restart=always`가 필요하다. 현재 Oracle 서버의 `Restart=on-failure` 설정에는 별도로 적용해야 한다. 운영 서버의 서비스 설정이나 실행 중인 JAR는 이번 작업에서 수정하지 않는다.

1.0.10을 이미 영구 로더로 설치한 서버는 로더 해시가 다르므로 1.0.11로 넘어갈 때 서버 재시작이 필요할 수 있다. 현재 Oracle 서버의 1.0.8 및 기존 1.0.9 로더에서는 이번 방식의 호환성을 확인한다.

검증: 실제 Bukkit `SimpleCommandMap`으로 등록·해제·재등록과 권한·중복 요청 처리를 확인했다. 배포 JAR는 1.0.9 배포 JAR와 영구 로더·밸런스·상태 형식이 같은지 별도로 검사한다.
