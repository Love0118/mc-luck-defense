# 0.19.3 — 후반 소환 방송 제한

소환 단계에 따라 전체 방송과 전체 접속자 대상 획득 사운드를 제한한다.

| 소환 단계 | 전체 방송 대상 |
|---|---|
| 10·100골드 / 1~999라운드 | 신화·태초·진 태초·미라클 |
| 1,000골드 / 1,000~2,499라운드 | 태초·진 태초·미라클 |
| 10,000골드 / 2,500라운드 이후 | 진 태초·미라클 |

플레이어별 현재 소환 단계를 기준으로 한다. 후반 세션이 있어도 초반 세션의 신화 방송을 막지 않는다. 제외된 등급도 직접 구매한 플레이어의 소환 피드백과 업적 집계는 유지한다. 일괄구매는 기존 개인 구매 피드백을 사용한다.

태초 뽑기 자체의 방송이 제외되더라도 합성으로 진 태초가 되면 진 태초 획득을 알린다. 특성 승급 알림에도 같은 단계별 제한을 적용한다. 한 번의 획득에 개인 희귀 소리와 전체 획득 소리를 중복 재생하지 않는다.

`mvn -B -ntp verify`: **334개 테스트 통과**. 999→1,000, 2,499→2,500 경계와 모든 등급·소환 단계 조합, 방송 제외 시 다른 플레이어의 소리 차단, 구매자 피드백, 진 태초 승급 방송을 검사했다.

상태 형식은 2를 유지한다. 0.19.2에서의 업데이트는 진행 중인 세션을 유지할 수 있다. 이전 형식인 0.19.1 이하에서 넘어올 때는 활성 세션 종료 후 적용한다. 소환 확률·전투 수치·시뮬레이션 정책은 바뀌지 않았다.

[CI #35931222997](https://github.com/Love0118/mc-luck-defense/actions/runs/35931222997)에서 통과한 공개 JAR의 SHA-256을 검증하고 로컬 서버 `plugins/update/mc-luck-defense-0.14.0.jar`에 내부 버전 0.19.3을 대기시켰다. 라이브 적용·재기동은 하지 않았다. 0.19.2 공개 빌드와 로더·밸런스·상태 형식 지문이 같으며 코어·시뮬레이터 클래스 68개도 바이트 단위로 동일하다.
