# 1.0.3 — 진 태초·미라클 소환 확률 상향

## 확률

| 구간 | 등급 | 기존 | 변경 |
|---|---|---:|---:|
| 500~999라운드 · 2,000골드 | 진 태초 | 0.002% | 0.005% |
| 1,000라운드부터 · 5,000골드 | 진 태초 | 0.005% | 0.012% |
| 1,000라운드부터 · 5,000골드 | 미라클 | 0.001% | 0.003% |

총 정수 가중치 100,000을 유지한다. 2,000골드 단계는 전설을 40.198%에서 40.195%로, 5,000골드 단계는 에픽을 50.494%에서 50.485%로 줄여 증가분을 충당한다. 단계 해금 라운드·구매 가격·판매가·합성·승급 규칙은 유지한다. 게임 내 확률 표시는 같은 소환 가중치에서 계산한다.

진 태초의 자연 소환 빈도는 두 단계에서 각각 기존의 2.5배와 2.4배, 미라클은 3배다. 기대 빈도는 각각 평균 20,000회·약 8,333회·약 33,333회당 1회이며 보장 횟수가 아니다. [전체 확률·판매 회수율](summon-economy.md)

## 적용

버전은 1.0.3, 런타임 상태 형식은 4다. 소환 확률 변경으로 밸런스 지문은 1.0.2와 달라진다. 따라서 1.0.2 성능 패치 때와 달리 **진행 중인 게임이 모두 끝난 뒤** `/mud update`를 실행해야 한다. 세션이 남아 있으면 기존 업데이터가 적용을 거절한다. 세션이 없으면 서버 재시작 없이 적용할 수 있다. `/mud version`에서 1.0.3을 확인한다.

## 검증

기존 확률 경계·10만 추첨값 전체 열거·판매 회수율·게임 내 확률 표시 검증의 기대값을 갱신했다. `mvn -B -ntp verify`에서 기존 350개 테스트가 모두 통과했다. 새 테스트 파일이나 항목은 추가하지 않았다.
