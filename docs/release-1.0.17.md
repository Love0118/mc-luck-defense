# 1.0.17 — 승급 화력 변화에 따른 후반 체력 보정

1.0.16은 직접 소환 태초의 기본 공격력을 유지했지만, 승급 신화·태초가 얻던 상속 공격력을 줄여 같은 등급·강화여도 이전보다 약해질 수 있었다. 400R 이후 적 체력을 그대로 둔 탓에 후반 난이도가 높아진 영향을 체력 곡선에 반영했다.

201~999R을 완화했다. 기준 체력은 300R 350만→40만, 400R 850만→180만, 500R 1,600만→600만이다. 600R부터 보정 폭을 줄여 1,000R에서 기존 체력 곡선으로 연결한다. 앵커 사이 압력은 연속적으로 증가하며 일반 적과 보스에 함께 적용한다.

타워 능력치·인접 등급 간격·승급 규칙, 특성, 배속, 구매 가격·확률·판매가는 1.0.16과 같다. 1~200R와 1,000R 이후 체력, 모든 라운드의 적 구성·속도·보상·등장 시점도 같다.

## 검증

442개 Java 테스트 및 Python 검증기 테스트 3개 통과. 전 구간 등장·속도·보상 보존, 1~200R·1,000~10,000R 체력 보존, 완화 구간과 라운드 경계의 연속 압력을 검증했다.

검증 시드를 조정 시드와 분리해 무특성·최고 4특성 각각 8,192판을 10,000R까지 관측했다. [도달률·원본·같은 시드 비교](balance/late-curve-1.0.17/REPORT.md)에 결과를 기록했다. 1.0.15와 초반 난이도가 다르므로 후반 비교는 200R 생존자 중 이후 도달 비율을 함께 사용한다. 초반부터의 전체 도달률을 이전과 같게 복원한 것은 아니다.

최고 4특성의 200R→500R 도달 비율은 1.0.15의 94.75% 대비 93.25%, 200R→2,000R은 0.735% 대비 0.726%다. 600~1,000R은 일부 더 어렵게 남아 있다. 최고 4특성을 주 기준으로 조정했으며 무특성 전체 500R 도달률은 1.0.15의 1.61%보다 높은 17.19%다.

이 검증은 10만 판이 아니며, 모든 기물·특성 조합에서 같은 체감을 보장하지 않는다. 이전에 상속 화력이 없던 직접 소환 태초 중심 조합은 더 쉬워질 수 있다.

## 배포·적용

beta에 배포하고 로컬·오라클 서버 update 폴더에 JAR를 준비한다. 서버 재시작·라이브 리로드는 실행하지 않는다. 새 세션부터 새 곡선을 사용하며, 기존 세션의 저장된 캠페인 설정은 강제 리로드로 소급 변경하지 않는다.
