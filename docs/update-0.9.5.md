# 0.9.5 대기 업데이트

- 네더 포탈 진입: 로비 스폰으로 텔레포트한 후 10틱(20 TPS 기준 약 0.5초) 뒤 참가·관전 GUI를 엽니다. 대기 중 게임 참가·접속 종료·로비 이탈 시 열지 않습니다.
- 전장 경계 복구: 플레이어·관전자 모두 가장 가까운 경계로 보정하고 시선과 비행 높이를 유지합니다. 관전 높이 상한과 바닥 이탈 보호는 유지합니다. 다른 월드로 이탈한 경우에는 전장 입구를 사용합니다. 라운드 전환 자체는 텔레포트를 호출하지 않습니다.
- 로비 1번 슬롯: 나침반 우클릭으로 게임 참가·관전 메뉴를 엽니다.
- 게임 참가자·관전자 8번 슬롯: 음표 블록 우클릭으로 개인 공격 음량 100% → 50% → 25% → 음소거를 전환합니다. 설정은 재접속 후에도 유지되며 다른 사람의 음량과 GUI 소리에 영향을 주지 않습니다.
- 기존 9번 슬롯 침대, 1번 이동·2번 판매 도구를 유지합니다. 교체한 슬롯은 백업하고 게임/관전 전환·퇴장 시 복원합니다.

검증: Java/native 전체 180개 테스트 통과. 실제 Paper 서버 3클라이언트 검사에서 포탈 스폰 이동 후 GUI 열림, 로비 나침반, 개인 음량 단계 표시, 플레이어 및 관전자 경계 복구·시선·비행 유지, 기존 배속·판매·관전 동작을 확인했습니다. 클라이언트 화면의 체감 지연과 실제 청취는 수동 검증하지 않았습니다.
