# 1.0.19 — 피해 기여도에 맞춘 연속 성장 곡선

1~200R은 유지하고, 이후는 강화 변경 전 1.0.15의 **200R 완료자 기준 후반 도달률**에 맞췄다. 최고 특성 이용자의 후반을 우선했으며, 전체 시작 판의 성공률을 과거와 같게 만드는 조정은 아니다.

200R 이후의 수동 체력 기준점을 제거하고 하나의 연속식으로 계산한다. 이전 전투에서 등급·강화별 실제 피해를 계측하여, 승급 화력 감소에 대한 보정이 후반으로 갈수록 줄어들게 했다. 1.0.18의 영구 15% 감소는 제거했다. 타워·강화·뽑기·판매·특성은 그대로다.

새로운 시드로 무특성·최고 4특성 각 8,192판, 총 16,384판을 재사용 없이 실행했다. 최고 4특성의 200R 완료자 기준 1,000R 도달은 이전 48.58% → 48.83%, 2,000R은 0.735% → 0.783%다. 300~400R은 여전히 약 3~4%p 낮으며 희귀 후반 결과에는 표본 오차가 있다. [전체 곡선·원본·한계](balance/smooth-growth-1.0.19/REPORT.md).

Java 테스트 448개와 Python 결과 검증기 테스트 3개를 통과했다. 동일 시드 128판의 1~200R 결과가 1.0.18과 완전히 일치하고, 배포용 실행기의 128판 결과도 최종 검증 자료와 일치했다. 저장 형식을 바꾸지 않았으며 기존/신규 코드 사이의 캠페인 저장·복원을 양방향 검사했다.

beta에 배포하고 로컬·오라클 update 폴더에 준비한다. 라이브 리로드·재시작은 하지 않는다. 진행 중 세션은 저장된 캠페인 설정을 유지하고 새 곡선은 새 세션부터 사용한다.
