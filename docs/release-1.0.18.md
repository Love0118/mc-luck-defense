# 1.0.18 — 1,000R 이후에도 이어지는 승급 태초 보정

1.0.17은 300~500R을 완화했지만 1,000R에서 이전 체력으로 돌아갔다. 승급 태초가 1,000R 이후에도 계속 피해를 담당하므로 후반 화력 감소에 맞춘 체력 보정을 무한 구간까지 이어 적용했다.

1,000R 이후 모든 라운드에서 일반 적·보스의 체력을 1.0.17 대비 85%로 낮춘다. 900R 기준 체력은 9,300만→8,800만, 1,000R은 약 1억 4,688만→1억 2,485만으로 변경하고 사이를 기하 보간한다. 800R까지는 1.0.17과 같다. 이후 성장 지수·압력 증가 방식은 같아서 라운드마다 적이 강해지면서도 기존 곡선보다 15% 낮은 체력이 계속 유지된다.

타워·승급·강화·특성·배속·뽑기·판매·적 구성·속도·보상·등장 시점은 변경하지 않았다.

## 검증

442개 Java 테스트 및 Python 결과 검증기 테스트 3개 통과. 1~800R 체력 보존과 1,000~10,000R 모든 몹의 체력 비율 85%, 10,001·20,000·100,000R에서도 같은 비율 유지, 전 구간 몹 구성·속도·보상·등장 시점 보존, 라운드 경계에서 압력이 연속적으로 상승하는 것을 확인했다.

무특성·최고 4특성 각각 8,192개 시드의 결과를 검증했다. 800R까지 패배한 14,095판은 코드·설정·원본 해시가 같은 구간이어서 완료 결과를 재사용하고, 영향을 받을 수 있는 2,289판은 게임 시작부터 다시 실행했다. 관측 상한은 10,000R이다. 재사용 경계를 변경된 900R로 잡으면 검증이 거절되는 것도 확인했다. [도달률·재사용 근거·원본](balance/endless-relief-1.0.18/REPORT.md)에 기록했다.

최고 4특성의 전체 시작 판 대비 2,000R 도달률은 49/8,192(0.598%), 2,500R은 29/8,192(0.354%)다. 1,500R은 1.0.17의 0.793%에서 3.052%로 완화되었다. 35% 감소안은 이 구간을 16.919%로 올려 채택하지 않았다. 1.0.15의 이전 표본은 2,048판에서 2,000R 0.732%였다. 동일한 도달률을 보장하는 비교는 아니다.

이 표본은 10만 판이 아니며, 모든 조합의 체감이나 이전과 같은 희귀 도달률을 보장하지 않는다.

## 배포·적용

beta 배포 및 로컬·오라클 update 폴더에 준비한다. 라이브 리로드·재시작은 실행하지 않는다. 새 세션부터 새 곡선을 사용하며, 진행 중 세션의 저장된 캠페인 설정은 강제 리로드로 소급 변경하지 않는다.
