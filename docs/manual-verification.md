# Paper 26.3 실제 서버 확인 목록

이 문서는 실행할 수동 체크리스트입니다. 항목이 작성되어 있다는 이유로 실제 서버에서 통과한 것으로 간주하지 않습니다.

1. Java 25 + Paper 26.3 build 19에서 JAR를 설치하고 플러그인 활성화 로그와 예외 유무를 확인합니다.
2. 관리자 A가 /mud create a, /mud create b로 전장 a·b를 생성합니다. A는 a, 플레이어 B는 b에 /mud join으로 참가합니다. 사용 중인 전장 참가가 거절되고 /moma 명령은 등록되지 않는지 확인합니다.
3. F키로 GUI가 열리고 보조 손 아이템이 바뀌지 않는지 확인합니다. 키 설정을 바꾸면 바뀐 키로 열리는지 확인합니다.
4. 소환을 반복해 바깥줄 북서쪽→시계 방향→안쪽 순서와 재화 10원 차감을 확인합니다. 빠른 더블클릭·Shift·숫자키·드래그로 아이템을 가져오거나 구매를 중복할 수 없는지 확인합니다.
5. 아군 좌클릭으로 선택 효과가 A에게만 보이는지 확인합니다. 빈 파란 칸 좌클릭으로 이동하고 선택이 해제되는지 확인합니다. 다른 아군 좌클릭은 선택 변경인지 확인합니다. 우클릭으로는 선택·이동이 없어야 합니다.
6. 경로·점유 칸·바닥 사이·전장 밖은 이동을 거절하고 선택을 유지해야 합니다. 벽 뒤의 포탑은 선택할 수 없어야 합니다. 배치 바닥과 포탑을 공격해도 파괴·피해가 없어야 합니다.
7. 일반~서사를 판매해 정해진 재화를 한 번만 받고 그 칸을 다음 소환에서 재사용하는지 확인합니다. 다른 포탑 위치는 바뀌지 않아야 합니다.
8. 참가 15초 후 첫 웨이브가 자동 출현하고 30초마다 라운드가 진행되어야 합니다. 적은 경로를 반복하며 남은 적은 다음 라운드에도 유지됩니다. 일반 적 처치 시 A에게만 6원, 보스는 30원이 지급되어야 합니다. /mud spawn으로 투입한 개발용 적은 보상이 없습니다.
9. 낮·비·네더 외형 몹·셜커·가스트 등을 확인합니다. 연소·변신·분열·자연 순간이동·아이템 드롭·접촉 밀림이 게임에 개입하지 않아야 합니다.
10. 전투 도중 포탑을 반복 이동해도 공격이 즉시 재발동하지 않아야 합니다. 광역·다중 역할과 상위 등급 특수효과의 서버 표현을 확인합니다.
11. 전설 이상 획득 방송과 판매 금지를 확인합니다. 상위 등급 동작은 자동 테스트로 검증되며, 실서버에서 강제 소환하려면 별도의 테스트 도구가 필요합니다. 공개 소환 확률을 바꾸지 않습니다.
12. 포탑 없이 적 한도를 채워 즉시 패배하는지 확인합니다. 추가 구매와 전투가 멈춰야 합니다.
13. /mud leave, 접속 종료, 정상 서버 종료에서 유닛·선택·GUI·청크 유지가 정리되고 위치와 게임 모드가 복구되는지 확인합니다. 재참가하면 새 라운드여야 합니다.
14. 서버 재시작 후 전장 지형과 목록이 유지되는지 확인합니다. 진행 중 라운드 복구는 이번 범위가 아닙니다.
15. 매 10라운드에 보스가 추가되고 100라운드의 모든 적을 잡으면 승리해야 합니다. 100라운드 이후 60초 정리 시간이 끝나도 적이 남으면 패배합니다. 종료 후 소환·판매·전투를 막아야 합니다.
16. /mud coins 또는 /mud spawn 사용 후 결과가 [관리자 개입]으로 표시되어야 합니다. 기존 config.yml의 개발용 수치를 수정해도 정식 campaign.properties 규칙을 덮어쓰지 않아야 합니다.
