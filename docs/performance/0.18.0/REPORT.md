# 20 TPS에서 공격속도·16배속 검증

로컬 전용 Paper 26.3-mud 서버를 20 TPS로 고정하고 10초 준비 후 약 30초를 측정했다. 라이브 서버에는 시험 플러그인을 설치하지 않았다.

- [SpeedSmokePlugin](../../../benchmarks/traits/SpeedSmokePlugin.java): 24종 × 1/2/4/8/16배속 × 공격속도 보너스 0/2/8% = 360개 전투 코어 인스턴스.
- 601회 서버 틱 콜백, 실측 20.000 TPS. 각 콜백에서 배속만큼 게임 틱을 처리한다.
- 태초 유닛 한 기와 사거리 내 사실상 정지한 고체력 적을 배치하고 실제 CombatEngine 피해 콜백을 센다.
- 모든 경우 이론상 공격 횟수와의 차이가 1회 이내였다. 16배속에서는 한 서버 틱 안에 여러 공격이 정상 처리된다.
- 별도 `SessionSpeedTest`는 실제 GameService의 1배/8배/16배 및 16→8→4→2→1 변경을 동일한 1,600게임 틱까지 실행했다. 적 체력·이동·감속·처치 보상·웨이브·공격 대기시간이 같으며, 무특성과 공속 +8% 각각 확인했다.

공격 간격의 소수 부분은 다음 공격에 누적한다. 공속 +8%는 같은 시간에 대략 1.08배 공격하며, 단순히 정수 틱으로 반올림되어 효과가 사라지지 않는다. 범위·대상 부족·적 이동이 있는 일반 전투의 실제 DPS는 사거리 안에 머무는 시간에도 좌우된다.

효과·소리는 서버 틱당 포탑의 마지막 공격만 표시하는 기존 정책을 유지한다. 시각 효과 횟수로 실제 피해 횟수를 세면 고배속 공격이 누락된 것처럼 보일 수 있다.

이 검사는 360개 순수 전투 인스턴스와 GameService 회귀 검사다. 20개 실제 플레이 세션의 엔티티·패킷 부하까지 16배속으로 측정한 성능 보장은 아니다. 해당 서버 틱이 50ms를 초과하면 현실 시간 기준 진행은 느려질 수 있다.
