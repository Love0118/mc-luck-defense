# 100골드 소환 판매 회수율

초반 3회 확률 보정을 제외한 기본 10골드 소환과 비교합니다. 소환 확률은 유지하고, 101라운드부터 소환한 유닛의 판매가를 조정합니다.

| 등급 | 10골드 소환 판매가 | 100골드 소환 판매가 |
|---|---:|---:|
| 일반 | 3 | 32 |
| 레어 | 6 | 65 |
| 고대 | 9 | 97 |
| 유물 | 16 | 173 |
| 서사 | 30 | 323 |
| 전설 | 60 | 60 |
| 에픽 | 150 | 150 |
| 신화 | 375 | 375 |
| 태초·진 태초 | 판매 불가 | 판매 불가 |

각 등급의 판매가는 `기존 판매가 × 기존 확률 × 10 ÷ 100골드 소환 확률`을 정수 반올림합니다. 상위 등급은 확률이 이미 10배이므로 판매가를 유지합니다.

판매 가능한 모든 결과를 즉시 판매한다고 가정한 1회당 평균 회수액:

- 10골드 소환: **6.36003골드**, 회수율 **63.6003%**.
- 변경 전 100골드 소환: **14.06423골드**, 회수율 **14.06423%**.
- 변경 후 100골드 소환: **63.5527골드**, 회수율 **63.5527%**.

회수율 차이는 0.0476%p입니다. 판매할 등급을 일부만 선택한 경우에도 등급별 기대 회수율이 반올림 오차 범위에서 유지됩니다.

소환 당시 판매가를 유닛에 보관합니다. 100라운드 이전 유닛은 이후에도 가격이 올라가지 않습니다. 서로 다른 소환 단계의 유닛이 강화·승급·흡수되어도 각 재료의 판매가를 합산합니다. 수동판매·자동판매·시뮬레이터가 같은 값을 사용하며 선택한 포탑 상세창에 실제 판매가를 표시합니다.

이는 판매 수익의 확률 전수 계산이며, 전투 승률이나 2000라운드 도달률을 다시 보정한 결과는 아닙니다. 후반 재투자 가능한 골드가 늘어나므로 기존 장기 시뮬레이션 결과에는 이 변경이 반영되지 않았습니다.
