# 1.0.9 — 로비 비행

로비의 일반 플레이어에게 `allowFlight`와 비행 상태를 켠다. 로비 접속, 사망 후 복귀, 게임 종료·퇴장, 관전 종료에 동일하게 적용한다. 로비로 순간이동한 뒤 비행 상태를 한 번 더 설정해 월드 이동으로 비행이 풀리지 않도록 한다. 실행 중 리로드할 때 이미 로비에 서 있는 플레이어에게도 즉시 적용한다.

게임 참가자와 관전자의 기존 비행 처리, 로비가 없는 서버에서 세션을 끝냈을 때 원래 비행 상태를 복원하는 동작은 유지한다. 1.0.8과 영구 로더·런타임 상태 형식 5가 같으므로 세션을 유지한 업데이트가 가능하다.

로컬 `mvn clean verify`에서 **358개 Java 테스트**, 결과 검증기 Python 테스트 **3개**가 통과했다. 로비 진입·리스폰·세션/관전 복귀와 로비가 없는 경우의 비행 복원 검사를 포함한다.
