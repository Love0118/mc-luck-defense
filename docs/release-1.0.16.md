# 1.0.16 — 인접 등급·초중반 재조정

같은 종에서 상위 등급 +0가 바로 아래 등급 +19보다 강하도록 일반→태초의 기본 공격력 간격을 단계마다 32배로 변경했다. 일반 +0를 1로 보면 일반 +19는 무특성 21.5, 최대 강화 특성에서 27.2이며 레어 +0는 32다. 태초·진 태초·미라클의 전투 수치는 그대로 유지했다.

강화 공식은 같다. 새 규칙의 +20 승급은 다음 등급 직접 소환과 동일한 전투 프로필을 사용한다. 이전 버전에서 저장된 기물의 상속 공격력은 강제로 제거하지 않는다. 다른 종·공격 타입까지 모든 상황에서 일률적인 서열을 보장하는 기준은 아니다.

상위 수치를 고정하고 역산하면서 작아진 하위 피해량에 맞춰 자동 배치 계산을 정규화하고, 선택 GUI에 작은 피해량이 0.0으로 표시되는 문제를 수정했다. 초중반 적 체력 곡선도 다시 맞췄다. 400R 이후 체력·보상, 판매가, 뽑기 가격·확률, 강화 공식, 배속 처리 방식은 1.0.15와 같다.

## 검증

442개 Java 테스트와 Python 결과 검증기 테스트 3개를 통과했다. 24종의 인접 등급 전투 1,440조건에서 역전이 없었으며 최대 강화 특성에서도 상위 +0가 하위 +19보다 최소 17.65% 강했다. 전체 등급·강화 프로필 10,560개와 연속 승급을 검증했다.

무특성·최고 4특성 각각 8,192판을 별도 검증 시드로 실행했다. 조정에 사용한 판은 이 수치에 포함하지 않는다. [도달률·원본·불확실성](balance/adjacent-1.0.16/REPORT.md)에 결과를 기록했다. 10만 판을 완료하거나 드문 2,000R 도달 목표를 확정한 것으로 해석하지 않는다.

## 적용

beta 배포만 수행하며 운영 서버에는 적용하지 않는다. 새 세션이 전체 새 밸런스를 사용한다. 기존 세션을 유지하는 강제 업데이트는 저장된 기물 능력치·상속값·판매가와 캠페인 설정을 소급 변경하지 않으므로, 진행 중 게임은 이번 시뮬레이션과 같은 조건이 아니다.

1.0.11~1.0.13에서 최초 전환할 때는 기존 명령 해제 결함 때문에 정상 재시작이 필요하다. 1.0.14 이후의 로더는 강제 밸런스 업데이트를 지원한다.
