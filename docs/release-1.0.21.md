# 1.0.21 — Oracle YouTube 쿠키 자동 갱신

매번 쿠키 파일을 수동으로 내보내는 부담을 줄이기 위해 Oracle에 전용 로그인 브라우저 프로필과 갱신 작업을 설치했다. 4시간마다 로그인 상태를 확인하고, 내보낸 후보 쿠키로 yt-dlp 검증이 성공했을 때 다운로드용 파일을 교체한다. 실패하거나 갱신 중 다른 작업이 파일을 바꿨으면 기존 파일을 유지한다.

Oracle에서 실제 로그인 성공, 인증 타임스탬프 쿠키 값 변경, 브라우저 종료 후 재실행 시 로그인 유지, 내보낸 쿠키 검증을 확인했다. systemd 서비스 실행도 성공했으며 타이머를 활성화했다. 게임 서버 프로세스는 재시작하지 않았다. 작업 동안만 브라우저를 실행하며 메모리 상한 512 MiB, CPU 상한 1코어를 적용한다.

새 갱신 로직 검사 11개를 포함해 유지보수 검사 19개가 통과했다. CI에도 유지보수 검사 실행을 추가했다. 플러그인 게임 코드·밸런스·저장 형식은 1.0.20과 같다. 보조 갱신 기능은 Oracle에 별도로 설치되는 구성으로, JAR 교체만으로 설치되지 않는다.

Google이 로그인 세션을 완전히 폐기하거나 추가 인증을 요구하면 다시 로그인해야 한다. 이 상황을 자동으로 해결하거나 영구 로그인을 보장하는 기능은 아니다. [설치·상태 확인·복구 방법](youtube-cookie-refresh.md).
