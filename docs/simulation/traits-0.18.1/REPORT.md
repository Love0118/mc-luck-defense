# 0.18.1 단일 대상 10~25% 보정 검증

동일한 256시드 × 7구성 = 1,792판을 700라운드까지 실행했다. 등급 확률은 바꾸지 않았다. 보정 대상은 최고 강화 한 종이며 동률이면 먼저 획득한 기물이다.

| 구성 | 100R | 300R | 500R | 700R |
|---|---:|---:|---:|---:|
| 무특성 | 27.34% (70/256) | 6.64% (17/256) | 1.17% (3/256) | 0.39% (1/256) |
| 10% 단계 | 26.95% (69/256) | 7.42% (19/256) | 2.34% (6/256) | 0.39% (1/256) |
| 15% 단계 | 26.95% (69/256) | 8.20% (21/256) | 1.95% (5/256) | 0.78% (2/256) |
| 20% 단계 | 26.95% (69/256) | 7.42% (19/256) | 2.34% (6/256) | 1.17% (3/256) |
| 25% 단계 | 26.95% (69/256) | 8.98% (23/256) | 3.91% (10/256) | 1.95% (5/256) |
| 시작 패시브 전체 | 37.89% (97/256) | 10.94% (28/256) | 2.34% (6/256) | 0.39% (1/256) |
| 패시브 + 25% 단계 | 38.67% (99/256) | 11.72% (30/256) | 4.69% (12/256) | 2.34% (6/256) |

희귀 도달의 표본 수가 작으므로 단계별 작은 역전을 성능 우열로 단정하지 않는다. 이전 10,000판 무특성 곡선을 대체하는 통계가 아니며, 특성 해금 계정과 새 계정을 구분해야 한다.

## 통제된 진 태초 승급 실험

전투·생존·다른 등급 없이 태초만 반복 도착시키고 첫 진 태초까지 센 결과다. 각 구성 2,000회이며 단위는 **일반 구매 횟수가 아닌 태초 도착 횟수**다.

| 구성 | 평균 | 중앙값 | 95백분위 |
|---|---:|---:|---:|
| 무특성 | 315.33 | 318 | 367 |
| 10% 단계 | 140.88 | 139 | 192 |
| 15% 단계 | 106.30 | 105 | 141 |
| 20% 단계 | 86.00 | 86 | 114 |
| 25% 단계 | 72.06 | 72 | 96 |

일반 게임의 진 태초 획득 확률·필요 총 골드로 직접 환산할 수 없다. 태초 확률은 그대로이므로 태초를 얻는 단계는 별도로 필요하다.

정확한 확률은 `ProgressionTraitTest.singleTargetGetsBonusPlusItsShareOfTheRemainingPoolAtEveryTier`에서 24종과 보정 난수 100구간의 전체 조합을 검사한다. 최고 단계 대상은 675/2400=28.125%, 나머지 각 종류는 75/2400=3.125%다.

재현:

```text
java -Xmx3g -cp target/classes dev.moma.sim.TraitBenchmarkMain 256 700 25000000 target/traits-0181 "none,duplicate_100,duplicate_500,duplicate_2000,duplicate_10000,all_passives,passives_duplicate"
javac -cp target/classes -d target/probes benchmarks/traits/DuplicatePromotionProbe.java
java -cp "target/classes;target/probes" dev.moma.benchmark.DuplicatePromotionProbe target/duplicate-promotion.csv
```
