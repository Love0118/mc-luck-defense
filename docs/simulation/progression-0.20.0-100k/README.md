# 중단한 대규모 실행

후반 곡선 검토를 우선하기 위해 로컬 대규모 실행을 중단했다. 완료된 체크포인트 기록은 총 6,492판이며 **최종 검증 결과가 아니다**. GitHub 대규모 실행도 취소됐다. 자동 업데이트 배포는 보류했다.

이 폴더의 `manifest.json`과 실행 명령은 중단한 4구성×10만 판 시도의 이력이다. 이는 원래 요청보다 과도하게 확대된 범위였다. 후반 곡선을 먼저 재설계한 뒤 최종 검증은 무특성·최고 특성 비교 **총 10만 판**으로 진행할 계획이다.

현재 도달률 근거는 별도 1,000판 [보정 표본](../curve-calibration-0.20.0/README.md)뿐이다. 중단한 부분 표본을 전체 10만 판처럼 합산하지 않는다. [곡선 재검토](../curve-review-0.20.0.md)를 먼저 따른다.
