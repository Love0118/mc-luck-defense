# 0.18.0 특성 비교 검증

동일한 256시드(25,000,000~25,000,255)를 8가지 구성으로 700라운드까지 실행했다. 총 2,048판이며, 자동 플레이어의 진행 표본이다. 특성 업적은 각 구성에서 이미 해금했다고 가정했다.

| 구성 | 100R 도달 | 300R 도달 | 500R 도달 | 700R 도달 |
|---|---:|---:|---:|---:|
| 무특성 | 27.34% (70/256) | 6.64% (17/256) | 1.17% (3/256) | 0.39% (1/256) |
| 투자 최대 3% | 31.64% (81/256) | 8.20% (21/256) | 3.12% (8/256) | 0.78% (2/256) |
| 투자 최대 12% | 33.59% (86/256) | 10.94% (28/256) | 2.34% (6/256) | 1.17% (3/256) |
| 재회 5% | 27.34% (70/256) | 7.42% (19/256) | 1.56% (4/256) | 0.39% (1/256) |
| 재회 15% | 27.34% (70/256) | 10.16% (26/256) | 3.12% (8/256) | 0.78% (2/256) |
| 시작 패시브 모두 해금 | 37.89% (97/256) | 10.94% (28/256) | 2.34% (6/256) | 0.39% (1/256) |
| 패시브 + 재회 15% | 37.50% (96/256) | 12.89% (33/256) | 3.52% (9/256) | 0.78% (2/256) |
| 패시브 + 투자 최대 12% | 51.17% (131/256) | 16.41% (42/256) | 8.20% (21/256) | 3.12% (8/256) |

256판은 희귀 도달률을 정밀 추정하기에는 작다. 이 표의 무특성 500R 값은 종전 10,000판의 2.54%를 대체하는 보정 목표가 아니다. 단계 간 작은 역전도 유한 표본·자동 플레이 정책의 영향을 받으므로 확정적인 우열로 해석하지 않는다. 기본 적 체력과 뽑기 등급 확률은 변경하지 않았다.

## 진 태초 승급에 대한 통제 실험

전투와 생존을 제외하고 태초만 계속 얻는 조건에서 첫 진 태초까지 필요한 태초 도착 횟수를 측정했다. 각 단계 2,000시드, 총 10,000회다. 일반 소환 횟수나 실제 진 태초 획득률이 아니다.

| 재회 보정 | 평균 태초 도착 횟수 | 중앙값 | 95백분위 |
|---|---:|---:|---:|
| 없음 | 315.33 | 318 | 367 |
| 5% | 205.17 | 201 | 273 |
| 8% | 161.33 | 159 | 218 |
| 12% | 124.14 | 123 | 167 |
| 15% | 106.16 | 105 | 142 |

최고 단계에서 평균 315.33 → 106.16회로 줄었다. 다만 실제 게임에서는 태초 획득 빈도·다른 등급의 승급·배치 공간·생존 여부가 영향을 주므로 이 감소율을 그대로 진 태초 획득 확률 증가로 환산할 수 없다. 태초 자체의 등급 확률은 그대로다.

공속·배속 검증은 [별도 보고서](../../performance/0.18.0/REPORT.md)에 있다. 재현:

```text
java -Xmx3g -cp target/classes dev.moma.sim.TraitBenchmarkMain 256 700 25000000 target/traits-018 "none,gold_spent_1000,gold_spent_10000000,duplicate_100,duplicate_10000,all_passives,passives_duplicate,passives_spending"
javac -cp target/classes -d target/probes benchmarks/traits/DuplicatePromotionProbe.java
java -cp "target/classes;target/probes" dev.moma.benchmark.DuplicatePromotionProbe target/duplicate-promotion.csv
```
