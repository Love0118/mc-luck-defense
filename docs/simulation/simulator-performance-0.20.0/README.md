# 시뮬레이터 성능 검증

밸런스를 바꾸기 전에 동일한 1,536판(무특성·최고 성장·최고 전투 각 512판)을 비교했다. 모든 기록은 시드별로 일치했다.

- 환경: Ryzen 5 9600X, 12 논리 프로세서, Microsoft OpenJDK 25.0.3, 최대 힙 6 GiB.
- 기존: 8개 작업자, 93.546초.
- 개선: 12개 작업자, 50.288초. 양쪽 모두 JFR 프로파일링을 켠 비교에서 1.86배 빨라졌다.
- 추가 개선 후 JFR을 끈 실행은 44.254초였고 동일한 1,536판 결과를 유지했다. 프로파일링 조건이 달라 이 수치를 주 비교 배율로 사용하지 않는다.

게임마다 독립 작업을 배정하고, 자동배치 계산 공간·경로 사거리 표를 재사용하며 동일 배치의 재계산을 줄였다. 전투 순서, 이동, 감속 만료와 구매 행동 한도는 유지했다. 배속을 올리기 위해 전투 틱을 건너뛰지 않는다.

CPU 수를 기본 작업자 수로 사용하며 `--threads`로 조절할 수 있다. 5초마다 완료 기록과 처리량·프로세스 CPU 사용률을 남긴다. `--resume`은 같은 실행 규칙과 실행 파일에 한해 미완료 시드부터 이어간다. 파일 끝의 미완성 기록만 잘라내며 중복·누락 시드는 검증한다.
