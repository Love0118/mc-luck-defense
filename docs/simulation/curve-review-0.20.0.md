# 0.20.0 곡선 재검토 — 이전 후보 기록

이 문서는 폐기한 후보 G와 당시 중단 사유를 보존한다. 이후 확정한 목표는 최고 특성 2,000R 0.01~0.02%, 실질 끝 구간 2,500R이다. [현재 연속 곡선과 검증](pressure-model-0.20.0/REPORT.md)을 우선한다.

## 확인된 문제

이전 완성 표본의 최고 성장 구성에서는 1,000라운드에 도달한 338판 모두 10,000라운드에 도달했다. 후반 생존률이 평평해지는 구조적 문제가 먼저 해결되어야 했다. 이후 후보를 충분히 검토하기 전에 구성별 10만 판으로 범위를 늘려 실행한 것은 잘못된 순서였다.

새 후보 G의 최고 합성·전투 1,000판은 다음과 같다.

| 도달 라운드 | 판 수 | 전체 도달률 |
|---:|---:|---:|
| 1,000 | 366 | 36.6% |
| 1,500 | 285 | 28.5% |
| 2,000 | 17 | 1.7% |
| 2,500 | 9 | 0.9% |
| 3,000 | 4 | 0.4% |
| 3,500 | 0 | 0% |

새 후보가 이전처럼 모두 10,000라운드까지 살아남는 것은 아니다. 그러나 1,500→2,000 구간에서 생존자의 약 94%가 탈락한다. 2,000라운드 목표 1~3%만 맞추고 전체 곡선이 적절하다고 판단해서는 안 된다. 이 표본의 2,000라운드 생존자 17판은 모두 최고 획득 등급이 진 태초였고, 미라클 획득 이후의 성장 분기는 검증하지 못했다.

## 검토 순서

1. **적 체력과 아군 성장의 상대 속도부터 검토한다.** 후반 보상은 라운드에 비례해 늘어 누적 골드가 대체로 제곱 규모로 증가한다. 이전 제곱 체력 연장과 겹치는 데다 승급·상위 소환이 성장 폭을 추가한다. 이는 평탄화의 원인 후보이며 실제 구매·합성·피해 기록으로 확인해야 한다.
2. **1,000~2,000의 관문을 분산한다.** 최고 특성 2,000라운드 1~3% 목표는 유지하되 마지막 500라운드에 탈락을 몰아넣은 후보를 그대로 확정하지 않는다.
3. **2,000 이후는 조건부 생존으로 검토한다.** 자연스럽게 2,000에 도달한 소규모 생존자 집단에서 2,500·3,000·4,000·5,000·7,500·10,000 도달률을 확인한다. 대부분이 끝까지 통과하면 큰 표본을 기다리지 않고 후보를 기각한다.
4. **미라클 성장 분기를 별도로 시험한다.** 자연 획득 표본과 명시적인 성장 스트레스 시험을 구분한다. 시험용으로 구성한 기물을 실제 소환 확률이나 도달률에 섞지 않는다.
5. **곡선 검토가 끝난 뒤에만 총 10만 판을 실행한다.** 무특성·최고 특성 비교를 로컬에서 진행한다. GitHub 대규모 시뮬레이션은 사용하지 않는다.

적을 강제로 제거하거나 특정 등급 보유 여부로 패배시키는 방식으로 목표 비율을 만들지 않는다. 공격·이동·소환·판매·합성 규칙과 틱 계산도 생략하지 않는다.

## 실행 상태

로컬 40만 판 시도와 GitHub 시도 모두 중단했다. 0.20.0 후보는 beta 소스에만 있으며 새 릴리스 및 라이브 서버 적용을 보류한다. 기존 update 폴더의 0.19.3 JAR는 변경하지 않았다.
