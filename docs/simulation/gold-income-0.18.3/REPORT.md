# 0.18.3 처치 골드 특성 효율 비교

**전장의 투자 5단계를 처치 골드 +2 / 3 / 4 / 6 / 8%로 채택했다.** 기존 누적 소모량에 따른 피해 증가는 제거했다. 골드 소모 업적 조건은 그대로다.

골드 +2%는 공속 +2%, 골드 +3%는 피해 +4%, 골드 +4%는 공속 +5%, 골드 +6%는 피해 +8%와 비슷한 진행 결과를 보였다. 최고 +8%는 초반 성장에 유리하지만 후기 도달률은 피해 +12%보다 낮다. 모든 라운드에서 동일한 효과라고 해석하지 않는다.

## 조건

- 실제 게임과 같은 Arena·Campaign·CombatEngine 및 기존 BALANCED 자동 플레이어를 사용했다. 몹 처치, 구매, 판매, 배치, 중복 합성, 승급을 실제로 진행했다.
- 탐색은 시드 26,000,000~26,000,999를 모든 구성에 공통 적용했다. 시작 패시브 없음/모두 해금의 두 조건에서 골드 +1/2/3/4/6/8/10%, 피해 +4/8/12%, 공속 +2/5/8%, 추가 특성 없음의 14구성씩, **28,000판**이다. 중복 실행한 두 구성은 한 번만 집계했다.
- 별도 검증은 새로운 시드 27,000,000~27,000,999를 사용했다. 시작 패시브 전체에 추가 특성 없음/골드 +8%/피해 +12%/공속 +8%의 **4,000판**이다. 탐색과 합쳐 중복 없는 비교 32,000판이다.
- 모든 특성은 이미 해금했다고 가정한다. 시작 패시브 전체는 첫 두 구매 에픽 이하 +1과 서사·전설·에픽·신화 초반 보정을 포함한다. 표의 특성은 하나만 장착한다.
- 6×6, 시작 30골드, 기존 체력 곡선·뽑기 확률·판매가를 유지했다. 강화 합성 ON이며 700라운드까지 실행했다. 숫자는 라운드 **진입률**이고 700 이후 생존이나 2,000라운드 도달 검증이 아니다.
- 골드 보너스는 일반 적·보스 처치 보상에만 적용한다. 판매·시작 골드·관리자 지급은 제외한다. 작은 보상은 정수 나머지를 누적하여 버리지 않는다.
- 단위 게임 틱으로 비교하며 클라이언트 지연이나 실제 플레이어의 구매·배치 속도는 모델링하지 않았다. 모든 특성 조합과 합성 OFF 플레이의 동등한 효율을 보장하는 결과도 아니다.

## 단계별 탐색 — 시작 패시브 없음

각 행 1,000판. 괄호가 없는 수치는 도달률이다.

| 구성 | 100R | 300R | 500R | 700R |
|---|---:|---:|---:|---:|
| 무특성 | 32.2% | 8.3% | 3.1% | 0.5% |
| 골드 +2% | 37.8% | 10.5% | 4.0% | 0.6% |
| 골드 +3% | 40.7% | 11.2% | 4.6% | 1.4% |
| 골드 +4% | 44.3% | 12.5% | 5.1% | 1.2% |
| 골드 +6% | 50.8% | 14.8% | 6.8% | 2.1% |
| 골드 +8% | 55.3% | 15.8% | 7.3% | 2.4% |
| 피해 +4% | 40.6% | 11.8% | 5.1% | 1.6% |
| 피해 +8% | 49.5% | 16.2% | 6.9% | 2.8% |
| 피해 +12% | 57.1% | 20.4% | 10.9% | 4.9% |
| 공속 +2% | 36.9% | 10.4% | 4.1% | 1.2% |
| 공속 +5% | 44.4% | 13.6% | 5.7% | 1.9% |
| 공속 +8% | 49.8% | 16.7% | 7.9% | 2.7% |

골드 +10%는 100R 59.3%, 500R 8.4%였다. 시작 패시브 전체에서는 100R 66.5%로 같은 조건의 피해 +12% 60.4%보다 높았다. 경제 특성이 초반 구매 횟수를 늘리는 효과를 고려해 최고 단계는 +8%로 보수적으로 잡았다. 희귀 도달 수가 적은 700R의 작은 단계 역전은 확정적 성능 역전으로 보지 않는다.

## 새로운 시드로 최고 단계 검증

모든 행에 시작 패시브 전체를 공통 적용했다. 각 1,000판이므로 60.3%는 603판이다.

| 추가 장착 | 100R | 300R | 500R | 700R | 평균 도달 라운드(700 상한) |
|---|---:|---:|---:|---:|---:|
| 없음 | 42.9% | 11.6% | 3.6% | 0.7% | 171.36 |
| 골드 +8% | 60.3% | 19.5% | 7.4% | 3.0% | 223.24 |
| 피해 +12% | 62.0% | 20.3% | 10.2% | 5.1% | 232.84 |
| 공속 +8% | 55.0% | 18.0% | 6.9% | 3.0% | 212.04 |

동일 시드 간 도달 여부 차이의 정규근사 95% 구간:

| 골드 +8%와 비교 | 100R 차이 (%p) | 500R 차이 (%p) |
|---|---:|---:|
| 피해 +12% | −1.7 [−4.76, +1.36] | −2.8 [−4.45, −1.15] |
| 공속 +8% | +5.3 [+2.42, +8.18] | +0.5 [−0.93, +1.93] |

따라서 최고 단계가 전 구간에서 피해·공속 특성을 압도하지는 않는다. 다만 공속보다 초반 도달에는 유리하다. 신뢰구간이 겹친다는 사실만으로 두 효과의 통계적 동등성이 증명된 것은 아니다. 기존 10,000판 무특성 곡선을 이번 표본으로 대체하거나 기본 적 체력을 재보정하지 않았다.

## 구현 검증

- Maven verify: 295개 테스트 통과. 다섯 단계 모두 0.1골드 보상 1,000회 누적의 정확한 지급액, 중복 수령 방지, 판매·시작 골드 제외를 검사했다.
- 소수 잔여분과 합성 OFF 설정의 직렬화·복원을 검사했다. 공개된 0.18.2 JAR로 작성한 구형 스냅샷도 실제 새 JAR로 읽어 기물·강화·잔액·누적 소모를 유지했다.
- GameService에서 공속 +8%와 새 골드 특성을 함께 장착하고 같은 1,600게임 틱을 1배/16배로 실행했을 때 전투·보상·진행 상태가 일치했다. 이는 실제 서버 TPS 부하 측정이 아니다.
- 기존 0.18.2 JAR의 무특성 시드 64개를 재실행해 새 결과와 모든 JSON 기록이 같음을 확인했다. [회귀 결과](baseline-regression.json).

## 원본·재현

탐색의 각 시드 결과와 짝 비교는 [discovery/analysis.json](discovery/analysis.json), 독립 검증은 [holdout/analysis.json](holdout/analysis.json)에 있다. 같은 폴더의 gzip JSONL에는 구매·판매·보상·라운드별 스냅샷을 보관했다. `none`은 해당 조건에서 추가 특성 없음이며, `passives-none`은 무패시브 신규 계정이 아니다.

오프라인 후보 수치는 검증 프로그램에서만 바꾼다. 서버 설정에 실험용 변경 기능을 추가하지 않았다.

```text
javac -cp target/classes -d target/gold-probe benchmarks/traits/GoldIncomeBenchmarkMain.java
java -Xmx3g -cp "target/classes;target/gold-probe" dev.moma.sim.GoldIncomeBenchmarkMain 1000 700 26000000 target/income-discovery "none,gold_1,gold_2,gold_3,gold_4,gold_6,gold_8,gold_10,damage_4,damage_8,damage_12,speed_2,speed_5,speed_8"
java -Xmx2g -cp "target/classes;target/gold-probe" dev.moma.sim.GoldIncomeBenchmarkMain 1000 700 27000000 target/income-holdout "none,gold_8,damage_12,speed_8" passives
python benchmarks/traits/summarize_gold_income.py target/income-analysis target/income-discovery
```

원 실행에서는 탐색을 세 작업으로 나누고 완료한 구성만 합쳤다. 중단된 상위 후보 작업과 중복 시드는 통계에 포함하지 않았다. 탐색 시드와 별도 검증 시드는 서로 섞어 짝 비교하지 않는다.
