# 중단한 이전 밸런스 실험

0.19.1 기준 실험은 시뮬레이터 병렬화와 전체 난이도 재조정 요청에 따라 중단했다. 60개 작업 중 51개가 완료됐고 9개는 취소됐다. 30만 판 완료 결과로 사용하지 않는다.

완료된 무특성 100,000판과 최고 성장 100,000판만 원본을 검증해 보관했다. 각각 시드 28,000,000~28,099,999이며, 도달률과 SHA-256은 `baseline-summary.json`에 있다. 최고 전투 구성은 미완료이므로 최종 비교 표에 포함하지 않는다.

핵심 관측: 최고 성장 구성에서 1,000라운드에 도달한 338판 모두 10,000라운드까지 도달했다. 이는 후반 조건부 생존률이 평평해지는 문제를 보여준다. 무특성은 100라운드 69.83%, 200라운드 15.241%, 300라운드 0.051%로 중반에 급격히 감소했다.

기록된 이전 실행의 `requestedVirtualSpeed=500`은 전투 틱을 묶는 크기다. 실제 속도를 500배로 제한하는 대기 기능은 없었다. 새 실행기는 이를 `batchTicks=500`, `requestedVirtualSpeed=unlimited`로 구분한다.
