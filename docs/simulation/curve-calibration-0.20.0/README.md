# 0.20.0 곡선 보정 과정

최종 후보 G는 시드 32,000,000~32,000,999에서 무특성·최고 합성/전투 각 1,000판으로 확인했다. 이 시드는 최종 10만 판 검증의 34,000,000번대 시드와 겹치지 않는다.

무특성 도달률은 30R 91.9%, 60R 72.6%, 100R 31.1%, 200R 21.5%, 300R 8.9%, 400R 4.8%, 500R 2.3%, 600R 1.4%, 700R 0.6%였다. 최고 합성/전투의 2,000R 도달률은 1.7%, 2,500R 0.9%, 3,000R 0.4%였다. 이는 **보정 표본**이며 최종 보고서의 확정 통계로 대체하지 않는다.

- A: 초반을 너무 어렵게 만든 후보. 100R 진입이 지나치게 낮아 기각.
- B: 1,000~2,000R 구간을 다수가 통과한 뒤 2,500~2,700R에 집중 탈락해 기각.
- C: 1,500R 이전에 특성 빌드 대부분이 끊겨 기각.
- D: 초중반은 접근했으나 최고 성장의 2,000~4,000R 도달률이 평평해 기각.
- E: 중복 특성이 포함된 최고 합성/전투 조합을 추가 확인. 2,000R 7.7%로 합의한 1~3%보다 높았음.
- F: 최고 합성/전투 2,000R 1.3%. 이후 G에서 300~700R와 후반 기울기를 함께 정리.
- G: 별도 10만 시드 검증에 사용할 후보로 선택.

각 폴더의 `rules.txt`와 `summary.csv`에 실제 범위·수치를 기록했다. `curve-early-c`는 100R까지만 실행한 보조 시험이므로 100R 이후 0은 미도달 통계가 아니다. C는 작업자 수를 4→12개로 바꾸며 체크포인트에서 재개했으며 기록된 시간은 재개 이후 구간만 포함한다. 배속 비교는 이 시간으로 하지 않는다.

최고 합성/전투 구성은 피해 +21%, 중복 기물 보정 +25%p, 강화 효율 +30%p와 모든 패시브다. D까지의 `top_combat`은 중복 보정 대신 공격속도 +8%를 사용한 별도 비교군이다. 같은 이름으로 취급하지 않는다.
