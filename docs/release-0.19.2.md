# 0.19.2 — 보이는 대기열·자리 교환·배속 선택

경기장 북쪽에 보라색 배치 칸 48개를 추가했다. 기본 6×6 전장에서는 6열×8줄이다. 대기 중인 몹도 실제 경기장에서 보이며 이름 앞에 `[대기]`를 표시한다. 대기 기물은 공격하거나 공격 대기시간을 진행하지 않는다.

필드와 대기열 사이에서 이동할 때 같은 몹 엔티티를 유지한다. 대기 기물에도 소유자 전용 선택 발광을 적용하고 판매·합성·세션 종료 시 엔티티를 정리한다. 관전자도 대기열을 볼 수 있지만 조작 권한은 소유자에게만 있다. 기존 전장의 전투 칸과 적 경로는 유지하며 대기열 쪽 이동 범위와 청크 유지 범위를 확장한다.

## 조작

- 2번 도구로 기물 좌클릭 → 선택.
- 선택한 상태에서 다른 자신의 기물 좌클릭 → 두 자리 교환 후 선택 해제.
- 필드↔필드, 필드↔대기열, 대기열↔대기열 교환을 지원한다. 36+48칸이 모두 차 있어도 교환할 수 있다.
- 같은 기물을 다시 클릭 → 선택 해제.
- 빈 전투 칸 클릭 → 기존 이동 방식. 수동 이동·교환은 자동 배치를 끈 상태에서 사용한다.
- 대기열 메뉴 우클릭 판매는 그 기물만 판매하며 기존 선택 기물과 교환하지 않는다.

교환은 강화·재료 판매가·공격 대기시간·연속 공격 상태를 초기화하지 않는다. 다른 플레이어의 기물, 종료된 게임, 이동 실패는 상태를 바꾸지 않는다.

F 메뉴의 시계는 이제 **배속 선택 메뉴**를 연다. 1·2·4·8·16·32배 중 원하는 항목을 클릭하면 적용하고 관리 메뉴로 돌아온다. 현재 속도는 초록색으로 표시한다. 돌아가기만 누르면 속도를 바꾸지 않는다.

## 업데이트

플러그인 버전은 **0.19.2**, 상태 형식은 **2**다. 이전 버전의 대기열 UUID는 실제 월드 엔티티가 아니므로 **0.19.1에서 넘어올 때는 활성 세션이 종료된 후 `/mud update`를 실행**한다. 서버 재기동은 필요하지 않다. 0.19.2의 같은 상태 형식으로 리로드하면 실제 대기 기물·선택·자리·전투 상태를 유지한다.

## 검증

`mvn -B -ntp verify`: **330개 테스트 통과**.

대기열 48개 좌표와 전투 영역 분리, 기존 전장 확장의 반복 실행, 기존 블록 충돌 거절, 세 가지 자리 교환, 꽉 찬 대기열 교환, 공격 상태 보존, 이동 실패 복구, 선택 발광, 판매 대상 보호, 세션 저장·복원·종료 정리, 배속 6개 선택과 중복·오래된 메뉴·다른 소유자·Shift·하단 클릭·드래그 차단을 검사했다.

소환 확률·적 체력·특성 수치·자동 플레이어 정책은 변경하지 않았다. 별도로 진행하는 구성별 100,000판 시뮬레이션은 시작 시 고정한 0.19.1 배포 파일을 사용한다. 완료 전 중간 결과를 최종 도달률로 제시하지 않는다.
