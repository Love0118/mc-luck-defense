# 1.0.20 — BGM 업로드 실패 원인 표시

YouTube 인증 만료·봇 확인·영상 접근 제한 때문에 BGM 등록이 실패하면 해당 원인을 채팅에 표시한다. 영상 정보 조회, 다운로드, 변환, 동기화 준비 중 어디에서 실패했는지 서버 로그에도 구분해 기록한다. 쿠키 내용이나 외부 도구의 원문 출력은 채팅·로그에 노출하지 않는다.

제보된 `40WtnlJwTM8`은 186초 영상으로, Oracle에서 영상 정보 조회 단계부터 `Sign in to confirm you’re not a bot` 오류가 발생했다. 9월 22일의 원본 쿠키 파일도 인증이 유효하지 않다는 경고가 발생했다. 로컬에서는 해당 영상 정보 조회가 성공했다. Oracle에서 기존 Dropbox 기본 팩은 HTTP 200으로 내려받았으며 저장된 SHA-1과 일치했다. 이번 제보는 YouTube 요청 단계에서 실패한 사례다.

이 패치는 실패 원인을 알려주며 만료된 외부 인증을 복구하지 않는다. 정상 업로드를 복구하려면 새 YouTube 로그인 쿠키가 필요하다. 개인 창에서 로그인하고 youtube.com 쿠키를 내보낸 뒤 그 창을 닫아 보관하는 방법은 [yt-dlp 공식 안내](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies)에 설명되어 있다.

Java 검사 453개와 Python 결과 검증기 검사 3개를 통과했다. 인증 만료와 봇 확인의 구분, 긴 오류 출력 끝의 원인 판정, 도구 실행 실패·시간 초과, 정상 종료 시 경고 허용, 비밀 값이 오류 메시지에 포함되지 않는 것을 확인했다. Oracle에서도 새 코드의 영상 정보 조회를 따로 실행하여 `METADATA / BOT_CHECK / exit=1`로 분류되고 구체적인 안내가 반환되는 것을 확인했다. 실행 중인 서버 코드를 교체한 검증은 아니다.

beta에 배포하고 로컬·Oracle update 폴더에 준비한다. 서버 재시작·라이브 리로드는 실행하지 않는다. 밸런스와 게임 저장 형식은 1.0.19와 같다.
