# 0.15.1 — 엔더 드래곤 정지 표시 수정

## 원인과 변경

플러그인은 모든 전장 몹의 서버 AI를 끄고 별도 경로 좌표를 적용합니다. 하지만 1.21.8 클라이언트의 엔더 드래곤은 NoAI가 설정되어 있으면 aiStep에서 일찍 반환하여 이동 보간·비행 이력·몸체 애니메이션 처리를 건너뜁니다. 따라서 서버 좌표 및 이동 패킷이 정상이어도 플레이어에게는 멈춰 보였습니다.

기존 서버 좌표 검사만으로는 이를 발견하지 못했습니다. 설치된 1.21.8 클라이언트 JAR와 [Mojang 공식 매핑](https://piston-data.mojang.com/v1/objects/bdeb624c3aefba11d9d40f34bc96176350b549b6/client.txt)을 대조했습니다. EnderDragon은 cps, aiStep은 e_, isNoAi는 gw로 매핑됩니다. 해당 바이트코드의 399~412 오프셋에서 NoAI일 때 반환하고, 클라이언트 보간 호출은 451~455 오프셋에 있습니다.

- 관리 대상 드래곤의 **클라이언트 메타데이터 사본에서만 NoAI 비트**를 해제합니다. 서버 AI·무적·무중력·비충돌·경로 이동 규칙은 유지합니다.
- 일반 몹과 관리 대상이 아닌 드래곤의 메타데이터는 바꾸지 않습니다. 왼손잡이 등 다른 몹 플래그도 보존합니다.
- 초기 생성·메타데이터 변경·재추적·묶음 패킷에 모두 적용합니다. 패킷 원본과 서버 엔티티 데이터를 수정하지 않습니다.
- 엔더 드래곤 모델의 정면이 일반 몹과 반대인 점을 반영해 이동 방향 회전을 180도 보정합니다. 일괄 이동과 개별 이동 모두 적용합니다.
- 기존 개인 선택 발광과 드래곤 처리를 PresentationMetadata에서 함께 수행합니다. 선택 발광은 계속 소유자에게만 보입니다.
- 플러그인 버전은 0.15.1이며 시작 로그도 실제 플러그인 버전을 표시합니다.

## 검증

Maven 테스트 **252개 통과**. 256가지 몹 플래그 조합에서 NoAI 비트만 해제되는지 검사하고, 두 바퀴 경로의 회전 및 일반 몹 방향 보존을 검사했습니다.

라이브와 분리된 로컬 Paper 26.3 서버에 ViaVersion/ViaBackwards를 설치하고, 1.21.8 클라이언트 두 개로 수정 전·후를 비교했습니다. 221틱 동안 서버의 실제 좌표, AI 비활성, 일괄·개별 이동을 검사했습니다.

| 항목 | 0.15.0 | 0.15.1 |
|---|---|---|
| 서버 드래곤 AI | 꺼짐 | 꺼짐 |
| 각 클라이언트가 받은 드래곤 이동 패킷 | 73개 | 73개 |
| 드래곤 몹 플래그 | 1, 1, 1, 3 | 0, 0, 0, 2 |
| NoAI 비트 | 계속 켜짐 | 계속 꺼짐 |
| 왼손잡이 비트 변경 | 보존 | 보존 |
| hide/show 후 다시 받은 생성 패킷 | 2회 | 2회 |
| 일반 좀비·비관리 드래곤 NoAI | 유지 | 유지 |
| 선택 발광 | 소유자만 | 소유자만 |

마지막 플래그 3→2는 NoAI만 제거하고 왼손잡이 비트는 보존했음을 뜻합니다. 결과는 실제 클라이언트 프로토콜 패킷 검사이며 그래픽 화면 자동 촬영 검증은 아닙니다.

[수정 전 검증](dragon-motion-0.15.1/baseline/verification.json) · [수정 후 검증](dragon-motion-0.15.1/fixed/verification.json). 원시 패킷을 압축 보관했습니다. fixture는 benchmarks/dragon, 실행기는 scripts/run_dragon_smoke.py입니다. 기존 0.15.0 특성·경제·라운드 코어는 변경하지 않았습니다.

## 적용

검증한 mc-luck-defense-0.15.1.jar를 사용합니다. 기존 서버의 plugins/update에는 설치된 플러그인과 같은 파일명으로 두어 다음 정상 재시작 때 교체합니다. 파일명이 이전 버전을 포함하더라도 내부 plugin.yml 버전은 0.15.1입니다. 라이브 서버를 재시작하거나 리로드하지 않습니다.
