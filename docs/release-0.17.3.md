# 0.17.3 — YouTube 로그인 쿠키 연결

`bgm.yml`의 `youtube-cookies-file`에 Netscape 형식의 쿠키 파일 경로를 설정하면 메타데이터 조회와 실제 음원 다운로드 모두 같은 인증을 사용한다. 빈 값은 기존 비로그인 동작을 유지한다. 절대 경로 또는 플러그인 데이터 폴더 기준 상대 경로를 사용할 수 있다. 파일을 읽을 수 없으면 다운로드를 시작하지 않는다.

쿠키 내용은 설정·명령 인자·로그·Git에 넣지 않는다. 서버에서는 별도 비공개 디렉터리에 보관하고 파일 권한을 `600`으로 제한한다. 파일을 교체하면 다음 다운로드가 새 내용을 읽는다. 경로 설정 변경은 안전 리로드 시 반영한다.

2026-09-22 Semion에서 사용자가 제공한 YouTube 전용 쿠키로 이전에 봇 확인 오류가 발생했던 곡 하나를 검증했다. 메타데이터 조회 약 3.8초, 음원 다운로드 포함 약 8.1초에 성공했고 약 3 MB의 WebM을 받았다. 전체 61곡 변환·업로드 완료를 의미하지는 않는다.

Semion의 비공개 쿠키 파일과 설정 경로는 준비했다. `/mud update`로 이 버전을 적용하면 시작 시 기존 미완료 팩 재생성을 시도한다. 서버 재시작은 필요하지 않다. 인증 만료나 YouTube 제한에 따라 이후 요청은 실패할 수 있다.

검증: Maven `verify` 275개 테스트 통과. 쿠키 미설정 시 기존 동작, 메타데이터·음원 명령의 인증 파일 경로 전달, 파일 누락·디렉터리 지정 시 다운로드 전 거절을 확인했다.

[최종 CI](https://github.com/Love0118/mc-luck-defense/actions/runs/35690494661)에서 빌드·테스트·시뮬레이션·게시 성공. 실제 업데이터로 게시된 `3ae8c5f0` 빌드를 다운로드하고 0.17.0과 영구 로더·밸런스·상태 스키마 지문이 같음을 확인했다. 번들 설정 파일도 기존 바이트를 유지하여 안전 리로드 호환성을 보존한다.

배포 JAR SHA-256: `e63826177f45ece7d41eb811e2d0710bd9644f5949ea5a9b2fb24d3b7182cb68`. Semion에서는 인증을 사용한 단일 곡 다운로드만 검증했고, 새 플러그인 적용과 전체 곡 마이그레이션은 아직 실행하지 않았다.
