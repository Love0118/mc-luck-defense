# 1.0.43 — 안전 업데이트 호환성 수정

Windows 설치본과 Linux 배포본의 줄바꿈 차이 때문에 내용이 같은 리소스도 변경으로 판정되던 문제를 수정했습니다. `config.yml`·`rewards.yml`·`wave-themes.tsv`는 로더 검사, `campaign.properties`는 밸런스 검사에 영향을 주었습니다.

Git 체크아웃에서 기존 설치본의 줄바꿈을 보존하고 빌드 리소스를 회귀 검사합니다. 로더 코드와 검증 절차, 실제 설정값, 밸런스, 세션 형식은 변경하지 않습니다.

1.0.40에서는 `/mud update`로 적용합니다. 이번 변경에는 `force`나 서버 재시작이 필요하지 않으며 게임 세션은 기존 안전 리로드 절차로 복원합니다.
