# 1.0.1 — 소환 알림과 포탑 도구

## 소환 알림

- 로비·관전·게임의 6번 칸에 종이를 지급한다. 우클릭으로 다른 세션의 소환 문구와 소리를 함께 켜거나 끈다. 기본값은 켜짐이며 설정은 플레이어 데이터에 저장한다.
- 자신의 게임과 현재 관전 중인 게임의 알림은 설정과 관계없이 받는다.
- 신화 전체 알림은 100라운드까지 보내고 101라운드부터 제외한다. 태초 문구는 계속 보내지만 101라운드부터 전체 소리는 보내지 않는다. 해당 세션의 플레이어와 관전자는 태초 소리를 듣는다.
- 태초 소리 크기는 0.7에서 0.35로 낮췄다. 같은 연속 구매 시도에서 태초가 5초 안에 다시 나오면 문구는 유지하고 소리만 생략한다. 구매를 끝내고 새로 시작하면 다시 소리를 낸다. 진 태초와 미라클의 알림은 기존 기준을 유지한다.

## 포탑 도구

- 3번 판매 도구로 포탑을 좌클릭하면 판매 대상을 선택한다. 선택한 포탑은 선택한 플레이어에게만 초록색 발광으로 보이며 우클릭하면 판매한다. 같은 포탑을 다시 좌클릭하거나 다른 아이템을 들면 선택을 해제한다.
- 2번 이동 도구의 선택도 다른 아이템을 들면 해제한다. 기존 이동·자리 교환 조작은 유지한다.

## 적용

버전은 1.0.1, 런타임 상태 형식은 5다. 도구 슬롯 백업 형식이 바뀌어 진행 중인 게임이 있으면 이전 버전에서의 업데이트를 거절한다. 게임이 모두 끝난 뒤 `/mud update`로 적용한다. 이전 기록 파일과 시즌 순위표는 변경하지 않는다.

## 검증

기존 테스트에서 알림 등급 경계와 개인 수신 설정, 태초 소리 범위·크기·연속 구매 억제, 도구 선택·판매 및 슬롯 복원을 확인했다. `mvn -B -ntp clean verify`에서 Java 테스트 350개가 통과했고 Paper 26.3 build 26 임시 서버에서 플러그인이 활성화됐다. 초록색 팀 패킷에 사용하는 Paper 메서드도 해당 서버 JAR에서 확인했다.
