# 0.19.0 — 상위 소환·미라클·48칸 대기열

1,000라운드 진입 시 1,000골드 소환, 2,500라운드 진입 시 10,000골드 소환으로 전환한다. 단일 기물을 뽑는 새로운 확률표이며 10회 묶음 상품이 아니다. 현재 가격과 확률은 F 메뉴의 책에서 확인한다. [전체 확률·판매가](summon-economy.md).

| 가격 | 해금 | 등장 등급과 확률 |
|---:|---:|---|
| 1,000골드 | 1,000R | 전설 70.099%, 에픽 20%, 신화 8%, 태초 1.9%, 진 태초 0.001% |
| 10,000골드 | 2,500R | 에픽 0.989%, 신화 80%, 태초 19%, 진 태초 0.01%, 미라클 0.001% |

태초 +20 → 진 태초, **진 태초 +20 → 미라클**로 즉시 승급한다. 미라클은 최종 등급으로 이후 강화도 유지하며 추가 등급으로 승급하지 않는다. 기본 피해는 진 태초의 34배, 사거리와 공격 간격은 동일하고 타입별 특수효과 단계는 5다. 강화 피해와 공격 대기시간을 계승한다. 미라클 이름표는 분홍→하늘색 그라데이션과 굵은 글씨로 표시한다.

태초는 자동판매 설정에 추가했다. 진 태초와 미라클은 직접 선택한 기물만 수동판매할 수 있다. 강화·합성 기물은 재료별 실제 판매가를 합산한다. 이후 소환 단계로 전환되어도 이미 보유한 기물의 가격을 다시 매기지 않는다.

## 대기열과 배치

- 전장 36칸과 별도로 **48기**를 저장한다. 전장이 가득 차면 새 기물은 대기열로 들어간다. 전장과 대기열이 모두 차면 새 종류의 구매는 거절하고 골드를 차감하지 않는다. 합성이 켜진 상태에서 일치하는 기물이 있으면 공간을 추가로 쓰지 않고 합성할 수 있다.
- 대기열은 월드 엔티티를 만들지 않으며 전투 대상 목록에 들어가지 않는다. 합성 대상과 중복 기물 확률 보정에는 포함한다.
- F 메뉴의 상자로 대기열을 연다. 첫 페이지 45기, 두 번째 페이지 3기다. 좌클릭으로 선택하면 이동 아이템을 들고 전장의 칸을 지정할 수 있다. 점유된 칸을 지정하면 그 기물과 교대한다. 우클릭은 수동판매다.
- 전장 기물을 선택한 뒤 대기열 메뉴의 ‘선택한 기물을 대기열로’ 버튼으로 보관한다. 직접 교대·보관하려면 자동 배치를 끈다.
- 자동 배치는 전체 보유 기물 중 **높은 등급 → 같은 등급의 기본 DPS** 순서로 36기를 선택하고, 사거리·공격력·경로 범위에 따라 위치를 계산한다. 나머지는 대기한다. 소환·판매 후 다시 계산하며 배치 이동으로 공격 대기시간을 초기화하지 않는다.
- 배치에 필요한 엔티티 생성이 실패하면 기존 전장과 대기열을 유지하고 새로 만든 엔티티를 정리한다. 대기열·강화·판매가·선택 상태는 세션 리로드에 보존한다.

## 32배속·500배속 시뮬레이션

F 배속 버튼과 `/mud speed 32`를 추가했다. 전투·웨이브·보상·일괄구매·자동 배치를 게임 틱마다 실행한다. 기존 서버 틱당 4회였던 구매 예산을 **게임 틱당 4회**로 바꿔 배속을 올려도 게임 시간 대비 구매량이 줄지 않는다. 일괄구매 자체는 돈이나 공간이 부족하면 종료하는 기존 동작이다.

같은 게임 틱 수를 처리하면 1배/32배의 구매·합성·배치·등급 전환·전투 결과가 같다. 실제 서버가 느리면 현실 시간 진행도 느려지며, 32배속에서 실제 20 TPS 유지 여부를 보장하는 부하 측정은 이번 기능 검증에 포함하지 않는다.

새 `ProgressionBenchmarkMain`은 10,000라운드를 목표로 무특성, 최고 성장 특성, 최고 전투 특성을 비교한다. 가상 20Hz 프레임 하나에 500게임 틱을 처리하며 내부 틱을 생략하지 않는다. 파일 생성용 실행은 인위적인 대기 없이 처리하고 실제 처리 배율은 별도로 기록한다. [3,000판 비교와 1/32/500 일치 검사](simulation/progression-0.19.0/REPORT.md).

## 업적·특성

2,250 / 2,500 / 3,000 / 4,000 / 5,000 / 6,000 / 7,500 / 9,000 / 10,000라운드 업적 9개와 미라클 누적 1 / 3 / 10 / 25 / 100회 획득 업적 5개를 추가했다. 총 104개 업적, 85개 보상이며 장착 78개·패시브 7개다. 장착 슬롯은 최대 3개를 유지한다.

후속 라운드 업적은 수비 교본 피해 +13~21%, 미라클 업적은 강화당 성장 +26~30%p를 해금한다. 같은 강화 계열인 담금질과 동시에 장착할 수 없다. 진 태초·미라클은 자연 추첨과 실제 승급 모두 획득으로 집계하고, 해당 등급 기물에 단순 강화만 추가한 경우는 다시 세지 않는다. 관리자 개입 판은 제외한다. [실제 목록](achievements-draft.md).
