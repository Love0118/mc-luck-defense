# 1.0.23 — 포탈섭으로 돌아가기

로비의 9번 칸에 **포탈섭으로 돌아가기** 침대를 지급한다. 주 손으로 우클릭하면 열린 메뉴를 닫고 BGM을 정리한 뒤 원래 인벤토리를 복원한다. 서버 리소스팩을 전부 해제한 다음 `stevegallery.kr:25565`로 전송한다. 블록·공중·엔티티 우클릭에서 사용할 수 있다.

게임·관전 중의 9번 칸 침대는 기존처럼 세션을 나가 로비로 돌아간다. 로비 밖, 게임·관전 중, 다른 아이템, 보조 손과 좌클릭으로는 서버 전송을 실행하지 않는다. 전송 API가 실패하면 로비 아이템을 복구하고 오류를 알린다.

## 업데이트 호환성

영구 로더·게임 저장 형식·밸런스 변경 없이 로비 도구와 상호작용만 추가했다. 안전 업데이트 활성화 시 로비 플레이어에게 새 침대를 지급하며 진행 중 세션과 관전 상태를 보존한다. 라이브 서버 재시작이나 리로드는 실행하지 않는다.

## 검증

리소스팩 해제 후 서버 전송 순서, 원래 인벤토리 복원과 중복 클릭 방지, 로비·활성 세션·도구 검사, 전송 실패 복구, 주 손 우클릭과 엔티티 우클릭을 검사했다. 전체 460개 테스트와 빌드가 통과했으며 마지막 엔티티 상호작용 보완 후 관련 검사를 다시 통과했다. 실제 클라이언트의 목적지 접속과 리소스팩 해제 화면은 확인하지 않았다.
