# 0.11.1 등록 길이 제한·KAKC 입력 보호

- YouTube 메타데이터에서 길이를 먼저 검사합니다. 정확히 300초(5:00)는 허용하고 300초를 초과하면 오디오 다운로드·FFmpeg 변환·Dropbox 업로드 전에 거절합니다.
- 길이 누락·0·음수·NaN·무한대와 실시간 영상도 거절합니다. 변환 및 분할 진입점에도 같은 제한을 적용합니다. 사용자에게 5분 초과 사유를 안내합니다.
- 설치된 KAKC 1.2는 AsyncPlayerChatEvent의 NORMAL 우선순위에서 취소 여부를 무시하고 영문을 변환합니다. BGM 입력은 LOWEST에서 원문을 먼저 확보하고 메시지·수신자 목록을 비워 취소합니다. HIGHEST에서 취소/비공개 상태를 재확인합니다.
- 레거시 경로를 사용하지 않는 Paper 채팅에서는 originalMessage()를 사용하므로 다른 핸들러가 수정한 message()에 의존하지 않습니다. 대기 중인 BGM 등록 및 Dropbox 인증 입력만 처리하며 일반 채팅과 KAKC 개인 설정은 변경하지 않습니다.
- 0.10.0 문서의 10분 제한은 이 버전부터 5분으로 변경됩니다.

검증: Java/native 전체 201개 테스트 통과. 실제 Paper 26.3 서버에서 운영 서버의 kakc.jar와 3클라이언트 통합 검사 통과. 영문 대소문자·기호가 포함된 YouTube URL 및 OAuth 테스트 문자열 원문 보존, 수신자 제거, 취소 유지, 일반 채팅 변환, 개인 모드 유지 확인.

운영 서버는 재시작하지 않았습니다. plugins/update/mc-luck-defense-0.9.5.jar에 내부 버전 0.11.1을 준비했습니다.
