# 1.0.5 — 네 번째 특성 슬롯의 시즌 기준 수정

네 번째 특성 슬롯은 **시즌 1에서 1,500라운드 도달**로만 해금한다. 1.0.4에서 프리시즌을 포함한 누적 최고 라운드로 열리던 문제를 수정했다.

- 기존 SQLite 순위표의 시즌 1 기록을 읽어 이미 달성한 계정에 적용한다. 프리시즌 기록은 가져오지 않는다.
- 이후 정상 게임의 시즌 1 도달 기록을 계정에 별도로 저장한다. 재접속·리로드·재시작으로 기록이 초기화되지 않는다.
- 1~3번 슬롯과 기존 특성·업적 해금 조건은 유지한다.
- 프리시즌 기록만으로 저장된 네 번째 장착은 계정 복원 시 제외하며 다음 게임에 적용하지 않는다. 해금한 특성 자체를 삭제하지 않는다.
- 누적 1,500라운드 업적을 이미 달성한 계정도 시즌 1에서 실제로 1,500라운드에 도달하면 네 번째 슬롯 안내를 한 번 받는다.
- 특성책의 네 번째 잠긴 슬롯에 시즌 1 조건을 표시한다.

## 업데이트

**1.0.4 → 1.0.5는 진행 중인 게임을 유지하며 `/mud update`로 적용**할 수 있다. 게임 상태 형식 5와 전투·소환·특성 수치를 유지한다. 이미 시작한 게임의 시작 특성은 종료까지 유지하며 다음 게임부터 교정된 장착을 적용한다.

1.0.3 이하에서는 게임 상태 형식과 특성 밸런스가 다르므로 진행 중인 게임이 모두 끝난 뒤 적용한다. `/mud version`으로 1.0.5를 확인한다. 라이브 서버의 게임을 종료하거나 서버를 재시작하지 않는다.

## 검증

기존 장착 저장·메뉴 테스트를 확장하고 시즌 기록 복원과 해금 안내를 함께 확인하는 회귀 테스트 한 개만 추가했다. 새 테스트 파일은 추가하지 않았다.

- 프리시즌 3,000라운드이지만 시즌 1 기록 없음·1,499라운드인 계정은 세 슬롯만 사용한다.
- 기존 SQLite 시즌 1 기록이 1,500라운드면 네 슬롯을 인정한다.
- 잘못 저장된 네 번째 장착은 제거하며 그 특성의 효과도 새 장착에 포함하지 않는다.
- 시즌 1의 1,499 → 1,500 경계에서 기존 누적 업적과 독립적으로 슬롯을 해금한다.
- 계정 복원과 이후 낮은 라운드 진입으로 시즌 1 최고 기록이 감소하거나 해금 안내가 반복되지 않는다.

전체 `mvn -B -ntp verify`에서 353개 테스트가 통과했다. 자동 배포는 별도로 전체 테스트와 시뮬레이션 검증을 통과한 빌드만 게시한다.
