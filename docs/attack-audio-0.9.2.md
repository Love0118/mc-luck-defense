# 0.9.2 공격 사운드

- 공격 타입 공통 사운드를 몹 종류별 사운드로 변경했습니다. 늑대 소리는 늑대만 사용합니다.
- 늑대 볼륨 인자는 0.35에서 0.12로 낮췄습니다. 다른 몹도 종류별로 0.18~0.30을 사용합니다. 이 수치는 체감 음량의 비율을 의미하지 않습니다.
- 스트레이·보그드는 바닐라와 동일하게 스켈레톤 활 소리를 공유합니다. 고유 공격 소리가 없는 몹은 해당 몹의 관련 소리를 사용합니다.
- 소리는 해당 게임 참가자와 관전자의 위치에서 각각 재생합니다. 비행 높이와 포탑까지의 거리로 끊기지 않으며 다른 세션에는 전달하지 않습니다. 포탑 방향에 따른 입체 음향은 제공하지 않습니다.
- 피해 대상이 여러 개여도 포탑당 서버 틱에 한 번만 재생하며, 배속 중에도 기존 중복 억제를 유지합니다.
- 파티클·피해 판정·이동·전투 수치는 변경하지 않았습니다.

사운드 변경만 적용한 별도 checkout에서 Java/native 전체 테스트 170개를 통과했습니다. 검사에는 모든 사운드 키의 Paper API 존재 여부, 늑대 사운드 독점 사용, 참가자·관전자 위치별 재생, 무관한 플레이어 제외, 다중 타격·배속 중 중복 억제가 포함됩니다. 실제 사람의 청취 평가는 포함하지 않습니다.

관전 모드 변경과 통합한 빌드는 172개 테스트를 통과했습니다. 실제 Paper 서버의 3클라이언트 검사에서도 24종의 사운드가 Registry.SOUNDS에 등록되어 있는지 확인했습니다. 2026-09-20 06:56 KST에 운영 서버에서 0.9.2 로드·기동 완료·25565 포트 대기를 확인했습니다.
