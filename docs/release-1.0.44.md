# 1.0.44 — 강제 업데이트의 자동 재시작

`/mud update force`는 안전 리로드가 가능하면 기존처럼 게임 세션을 유지해 적용합니다. 로더·의존성·플러그인 설정 변경 또는 진행 중 세션과 다른 상태 형식 때문에 재시작이 필요한 경우에는 검증한 업데이트 JAR를 준비하고, 전체 안내 후 5초 뒤 서버를 정상 종료합니다. 오라클의 기존 운영 서비스가 서버를 다시 기동하며 Paper가 업데이트를 설치합니다. 재시작하면 진행 중인 게임은 종료됩니다.

일반 `/mud update`는 재시작이 필요한 업데이트를 계속 거절합니다. `force`라도 다운로드 실패, 손상된 JAR, 세션 복원 실패를 재시작으로 우회하지 않습니다.

기존 설치본은 런타임 캐시에 보존하고 업데이트는 기존 설치 파일명으로 임시 파일에 복사·검증한 뒤 배치합니다. 다른 업데이트가 이미 준비되어 있으면 덮어쓰지 않습니다. 재시작 예약이 실패하면 이번 작업이 만든 대기 파일만 제거하며, 종료 직전에도 체크섬을 다시 검사합니다. 대기 중에는 추가 업데이트·리로드·롤백을 거절합니다.

이번 버전은 로더가 변경되어 최초 적용 시 정상 재시작 한 번이 필요합니다. 설치 후부터 위 명령으로 이후 재시작 필요 업데이트를 자동 처리할 수 있습니다. 명령어와 관리자 권한은 기존과 같습니다.
