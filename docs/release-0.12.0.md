# 0.12.0 — 합성·무한 라운드·최고 기록·BGM 캐시

## 판매

전설 60골드, 에픽 150골드, 신화 375골드. 선택 판매와 등급별 자동판매 모두 지원하며 태초만 판매할 수 없습니다. F 메뉴 하단에 일반부터 신화까지 8개 자동판매 버튼을 배치합니다. ON으로 바꾸면 보유 중인 해당 등급도 판매합니다.

소환 10골드 기준 해당 등급 하나의 평균 획득 비용은 전설 2,000골드(0.5%), 에픽 5,000골드(0.2%), 신화 12,500골드(0.08%)입니다. 판매가는 각각 평균 비용의 3%입니다. 특정 종까지 지정한 획득 비용은 이보다 24배 큽니다. 기본 확률에서 판매 가능 등급을 모두 환전한 소환당 회수 기댓값은 6.36003골드이며 소환 비용 10골드보다 낮습니다.

## 자동합성

동일 종·동일 등급을 소환하면 기존 포탑의 강화가 1 증가합니다. 다른 종·등급과 합쳐지지 않습니다. 자동판매가 켜진 등급은 판매를 우선합니다. 합성은 기존 엔티티·위치·공격 대기시간·연속 공격 상태를 유지합니다. 이름과 선택 정보에 +강화를 표시하고 세션 참가자·관전자에게 폭죽 입자와 폭발음을 보냅니다. 피해를 주는 실제 폭죽 엔티티는 만들지 않습니다.

피해 배율은 1 + 강화 + floor(강화 / 5) × 0.5입니다. +1은 200%, +4는 500%, +5는 650%, +10은 1,200%입니다. 사거리·공격 주기·대상 수는 유지합니다. 강화 포탑 판매가는 등급 판매가 × (강화 + 1)입니다. 전설 +2는 180골드입니다. 기존 구매 계약대로 빈 칸이 없는 상태에서는 구매를 거절하며 돈을 차감하지 않습니다.

## 무한 라운드와 순위

실제 게임은 100라운드 승리·최종 정리 제한을 제거했습니다. 101라운드 이후 테마는 100개를 반복하고, 체력은 100라운드 기준으로 매 라운드 8%씩 증가합니다. 100 이후 일반 몹 수와 골드 보상은 기존 후반 수준을 유지합니다. 보스는 10라운드마다 등장합니다. 현재 라운드만 생성하므로 라운드 수만큼 메모리가 늘지 않습니다.

스폰의 수평 시선 방향으로 5블록 앞, 스폰 높이보다 2.8블록 위에 최고 도달 라운드 TOP 10을 표시합니다. UUID당 최고 기록 1개를 보관하며 동점은 UUID 순으로 고정합니다. 관리자 개입 세션은 기록하지 않습니다. plugins/MCLuckDefense/round-records.properties에 5초 간격 및 종료 시 저장합니다. 비정상 종료 시 마지막 저장 이후 최대 5초의 기록이 누락될 수 있습니다.

기존 독립 시뮬레이터의 기본 100라운드 비교 모드는 유지합니다. 실제 게임과 합성·판매·전투 규칙을 공유하지만, 과거 1% 클리어율은 이번 합성·무한 모드에 대한 검증 수치가 아닙니다. 새 난이도 곡선의 장기 분포는 별도 조정 대상입니다.

## BGM 적용과 캐시

현재 필요한 모든 곡의 팩에 SUCCESSFULLY_LOADED 응답이 와야 재생에 합류합니다. ACCEPTED와 DOWNLOADED만으로 재생하지 않습니다. 적용된 팩은 동시에 누적해 유지하고 로비 복귀·관전 종료·세션 전환·BGM OFF에서 해제하지 않습니다. 동일 콘텐츠 해시라면 URL 복구만으로 다시 적용하지 않습니다. 다른 곡으로 바꿀 때는 소리만 멈춥니다.

변경된 곡은 같은 곡의 이전 해시 버전만 교체합니다. 실패한 현재 필요 팩은 OFF→ON으로 재요청합니다. 필요 없는 캐시 팩의 실패가 현재 재생을 중단하지 않습니다. 접속 종료 시 서버의 적용 상태는 폐기합니다. 재접속에서는 같은 UUID·해시로 요청하되 새로운 적용 완료 응답을 기다립니다. 클라이언트 디스크 캐시 유지 자체는 Minecraft가 결정합니다.

Via 검증은 benchmarks/bgm/run_via.py의 격리 서버에서 1.21.8 프로토콜 클라이언트로 수행합니다. ZIP 수신·SHA-1·UUID 응답·모든 팩 적용 대기·RECORD 채널·관전 재입장 시 재요청/해제 여부를 확인합니다. 프로토콜 테스트는 실제 게임 클라이언트의 오디오 렌더링이나 Dropbox 계정 인증을 대신하지 않습니다.
