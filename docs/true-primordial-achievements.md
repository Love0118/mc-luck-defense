# 진 태초 업적과 방송

진 태초 승급 누적 1·2·3·5·10·20·30·50·75·100회 업적 10개를 추가해 총 60개입니다. 모두 챌린지 프레임·완료음·엔드 수정 아이콘을 사용합니다. 기존 50개의 식별자와 저장 데이터는 유지합니다.

실제 구매 후 합성 결과가 진 태초로 승급한 경우 1회를 누적합니다. 기존 진 태초가 새로 승급한 같은 포탑을 흡수해도 새 승급 1회로 집계합니다. 관리자 개입 판은 업적에서 제외합니다. 원래 뽑힌 태초는 기존 태초 소환 횟수에도 정상 반영합니다. 이전 버전에 승급 기록이 없어 과거 승급은 소급하지 않습니다.

진 태초 승급은 서버 전체에 플레이어명·등급·포탑명을 진한 빨강 굵은 글씨로 방송하고 모든 접속자의 위치에서 전용 음높이의 챌린지 완료음을 재생합니다. 동일 구매의 원래 뽑기 방송은 생략하여 승급 방송을 한 번만 보냅니다. 업적 최초 완료 토스트/소리는 별도로 발생합니다.

2026-09-21 검증: 확정된 0.13.0에서 격리 빌드, 테스트 221개 통과. 1.21.8 프로토콜 클라이언트와 Via를 사용한 두 번의 정상 부팅에서 업적 60개 등록·완료, 진 태초 누적 100회 저장, 재접속 후 60개 완료 유지, 중복 완료 없음 확인. 난이도 보정 중인 파일은 이 빌드에 포함하지 않았습니다.
