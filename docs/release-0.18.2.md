# 0.18.2 — 특성 GUI 문구 정리

전우의 재회 설명을 `가장 강화수치가 높은 기물 등장확률 10%p 증가`로 변경했다. 단계에 따라 10/15/20/25%p를 표시한다.

특성 선택·소환 확률 GUI에서 확률 배분 방식, 획득 시 종료, 고대·유물 보정 유지, 원래 등급 판매가, 강화 계승 계산식 등의 부가 설명을 제거했다. 효과·해금 조건·진행도·장착 상태·남은 횟수를 간단히 표시한다.

문구만 정리했으며 추첨·등급 승급·종료 조건·피해 수치는 변경하지 않았다. Maven 빌드와 기존 테스트 284개가 통과했다.

[CI](https://github.com/Love0118/mc-luck-defense/actions/runs/35791344315)의 빌드·테스트·게시 성공. 게시된 `637b2f54` 파일을 실제 업데이터로 내려받아 검증하고 로컬 update 폴더에 준비했다. 라이브에는 적용하지 않았다. 기존 로더는 특성 설명을 포함한 클래스 지문도 비교하므로 세션이 없을 때 `/mud update`로 적용한다.
