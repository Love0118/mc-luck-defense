# 1.0.15 — 하위 등급 격차와 공통 판매가

일반 +9가 같은 종의 전설 +0보다 강하던 등급 압축을 조정했다. 일반~신화의 공격력 배율은 `1 / 2 / 4 / 8 / 16 / 32 / 80 / 180`으로 변경했다. 태초·진 태초·미라클은 공격력 배율 `4,800 / 480,000 / 48,000,000`, 공속·사거리·특수효과를 유지했다. 강화 공식과 승급 상속, 자동 배치 정책은 유지했다.

전설 +0는 같은 종의 일반 +9 기본 DPS보다 3.81~4.27배 강하다. 최대 강화 특성의 일반 +19보다도 1.47~1.65배 강하다. 태초 +0도 최대 강화 특성의 신화 +19 기본 DPS보다 강하다. 모든 24종을 검증했다. 합성 이력으로 생기는 같은 등급·강화의 공격력 차이는 남아 있으며, 이를 없앴다고 주장하지 않는다.

첫 구매 일반·레어의 약화와 상위 등급 강화에 맞춰 1~1,000R 체력 곡선을 조정했다. 1,000~10,000R 적 체력·보상은 이전과 수치가 일치한다. 시작 골드·웨이브 구성·적 이동 속도·강화·소환 처리 빈도는 변경하지 않았다.

## 판매·확률

- 판매 단가는 전 소환 단계에서 공통이다. 500·1,000R에만 붙던 판매가 가산을 제거했다.
- 공통 단가: 에픽 300→400, 신화 750→1,000, 태초 1,000→1,500, 진 태초 20,000→30,000, 미라클 420,000→630,000골드. 일반~전설은 기존 단가다.
- 기존 구매의 기록된 판매가는 재평가하지 않는다. 합성은 기존 재료값에 새 재료값만 더한다.
- 500R 뽑기 2,000→1,400골드, 1,000R 뽑기 5,000→3,300골드. 10·100골드 뽑기 확률은 유지한다.
- 진 태초 확률 0.005%/0.012%, 미라클 0.003%는 유지하고 나머지 후반 확률을 조정했다. 가격과 환급을 함께 계산하면 목표를 보유하고 다른 결과를 모두 판매하는 기준의 진 태초/미라클 획득 기대 순지출은 이전 대비 약 -2.60%/-0.53%/-0.32%다.
- 단순한 총 구매액·전부 보유 기준에서는 이전과 같은 획득량이 아니다. 판매 환급을 포함한 기준과 구분한다.

## 검증·적용

414개 Java 테스트, Python 결과 검증기 테스트 3개 통과. 24종·등급·강화 프로필 11,232개, 실제 전투 조건 864개, 특수효과 검증 792개를 재계산했다. 별도 조정 시드와 분리된 독립 라운드 시뮬레이션은 위 보고서에 판 수·시드·도달률·불확실성을 기록했다. 이번 검증은 10만 판 완료 보고가 아니다.

밸런스 변경이므로 기본 세션 유지 업데이트는 진행 중 게임이 있으면 거절한다. 1.0.14부터는 `/mud update force`로 변경을 허용할 수 있지만, 이미 배치한 기물의 저장 능력치와 진행 중 캠페인 설정은 소급 재계산하지 않는다. 새 게임이 전체 새 설정을 사용한다. 기존 구매의 판매가도 그대로 유지한다.

1.0.11~1.0.13에서는 기존 런타임 명령 해제 결함이 먼저 실행되므로, 1.0.14 이후로 최초 전환할 때 정상 재시작이 필요하다. 이번 작업은 beta 배포까지 수행하며 운영 서버에는 적용하지 않는다.
