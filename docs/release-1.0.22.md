# 1.0.22 — 환경설정과 알림 선택

6번 칸의 다른 세션 소환 알림 아이템을 비교기 모양의 **환경설정** 아이템으로 변경했다. 로비·게임·관전에서 우클릭하면 GUI가 열린다.

- **내 소환 알림 ON/OFF:** 자신이 획득한 기물의 소환·특성 승급 방송과 방송 소리.
- **다른 소환 알림 ON/OFF:** 다른 플레이어의 소환·특성 승급 방송과 방송 소리. 관전 중인 세션도 포함한다.
- **라운드 알림 ON/OFF:** 자신의 게임에서 `라운드 n · 오버월드`처럼 표시되는 라운드 시작 채팅.

기존 다른 세션 알림 설정을 그대로 가져오며 새 항목은 기본 ON이다. 설정은 플레이어 데이터에 저장되어 게임 종료·재접속·업데이트 후에도 유지된다. 클릭하면 상태 색상이 즉시 바뀌고 조작 소리가 난다. 구매·판매·GUI 조작의 피드백 소리는 소환 방송 설정과 별개다. 라운드 채팅을 끄더라도 라운드 진행·기록·업적·액션바는 계속 갱신된다.

## 업데이트 호환성

영구 로더·게임 저장 형식·밸런스는 1.0.21과 동일하다. 설정을 세션 저장 구조에 추가하지 않고 기존 플레이어 데이터 키를 보존했으며, 아이템 식별자와 인벤토리 백업 형식도 유지했다. 안전 업데이트 시 활성 플레이어·관전자의 아이템은 환경설정으로 갱신된다. 열린 GUI는 기존 런타임 정리 절차로 닫힌다.

1.0.21에서 일반 `/mud update`로 세션을 유지하며 교체할 수 있다. beta 배포와 update 폴더 준비까지만 수행하며 라이브 업데이트·리로드·재시작은 실행하지 않는다.

1.0.20에서도 일반 업데이트 호환성 검사를 통과했다. **실제 로컬 Paper 서버에서 진행 중 세션·36개 배치 기물·4개 대기 기물·적·관전자를 유지하며 1.0.20 → 1.0.22를 교체**하는 추가 검증도 통과했다. [서버 테스트 조건·결과](notification-reload-1.0.20.md).

## 검증

기존 OFF 값 보존, 세 항목의 독립 저장, 소유자·관전자·다른 세션의 방송과 소리 필터링, GUI 중복 클릭·다른 플레이어·닫힌 메뉴·이동 클릭·드래그 거절, 라운드 알림 OFF 상태의 게임 진행과 업적 기록을 검사했다. 기존 안전 업데이트·롤백·게임 상태 전송 검사도 함께 실행했다. 실제 업데이트는 분리된 로컬 테스트 서버에서 수행했다.
