# 0.19.1 — 가득 찬 대기열의 재추첨 방지

[0.19.0의 상위 소환·미라클·48칸 대기열·32배속·새 업적](release-0.19.0.md)을 포함한다.

전장과 대기열이 모두 찬 상태에서도 일치하는 기물은 합성할 수 있다. 다만 새로운 종류가 나와 공간 부족으로 구매하지 못했을 때, 다시 눌러서 새로운 확률 결과를 얻지는 못하도록 해당 결과를 보관한다. 빈 칸을 만들고 구매하면 그 결과를 지급하며 골드는 성공한 구매에서만 차감한다.

보관한 결과는 재접속/세션 리로드로 초기화되지 않는다. 소환 단계가 상위 단계로 전환되면 이전 단계 결과를 버리고 새 가격의 확률표를 사용한다. 단계를 되돌리는 방식으로 반복 초기화할 수 없다.

무료 재시도에 의한 확률 편향, 저장 복원, 공간 확보 후 정확한 결과 지급, 새 단계 전환을 추가 검사했다. Maven verify **318개 테스트**를 통과했다. 0.19.0의 시뮬레이션 자동 플레이어는 총 공간이 차면 판매 후 구매하므로 이 수정의 재시도 경로를 사용하지 않는다.

현재 배포는 0.19.1이다. 이전 버전에서 밸런스 변경을 포함하므로 진행 중인 게임을 마친 뒤 `/mud update`로 적용한다.
